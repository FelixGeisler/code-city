= 6. Runtime View

== Local

`codecity open .` reads a checkout, builds the city model, and serves the viewer
on `127.0.0.1`.

== Public GitHub

The hosted service downloads a bounded public snapshot, analyzes it in an
isolated worker, and returns derived artifacts.

== Print

`npm run print:demo` writes a 93 x 48 x 33.8 mm labelled 3MF and private JSON
legend. PrusaSlicer imports the 3MF as one object with five aligned tool parts.

[source,powershell]
----
npm run cli -- export `
  --model examples\demo-city.json `
  --profile profiles\prusa-xl-5t.json `
  --format 3mf `
  --scale 3 `
  --labels auto `
  --legend build\print\code-city-demo.legend.json `
  --output build\print\code-city-demo.3mf
----

STL, FLOW-sized tiling, arbitrary fonts and logos, and slicer settings remain
separate work.
