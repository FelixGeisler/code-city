= 5. Building Block View

[source,text]
----
apps/cli ----\
               packages/analyzer --> packages/core --> packages/exporter
apps/server --/          |                 |                  |
       |                 +---- snapshots   +---- model -------+
       +---- jobs/artifacts/publications          |
                                                 v
                                         apps/viewer
----

[cols="1,2"]
|===
|Block |Responsibility

|`packages/core`
|Versioned city/evolution contracts, validation, metric mapping, deterministic
layout semantics, and print planning

|`packages/analyzer`
|Source discovery, snapshot normalization, Git adapters, language analysis,
history analysis, and credential-isolated acquisition

|`packages/exporter`
|Format-neutral printable geometry plus deterministic STL, 3MF, plate, legend,
and calibration serialization

|`apps/server`
|Same-origin HTTP boundary, authorization, durable jobs, uploads, artifacts,
retained source, published snapshots, and optional provider adapters

|`apps/viewer`
|3D exploration, import orchestration, evolution playback, findings, source
inspection, publication, and local image/print export

|`apps/cli`
|Local analysis, serving, and export commands over the same packages

|Native helpers
|Bundled Roslyn analysis and ephemeral Git credential exchange behind bounded
process protocols
|===

Dependencies point inward through explicit contracts: applications orchestrate;
core does not depend on UI, server, Git, or exporter implementations.
