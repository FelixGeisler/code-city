= 5. Building Block View

[cols="1,2"]
|===
|Block |Responsibility

|Repository source
|Materialize local, GitHub, or generic Git snapshots

|Analyzer
|Emit shared facts through pinned TypeScript and syntax-only Roslyn front ends

|Layout
|Place districts and buildings deterministically

|City model
|Versioned contract between all blocks

|Viewer
|Render and inspect the city

|Print planner
|Validate geometry and map semantic groups to printer capabilities

|Exporters
|Write 3MF plus a private code legend from validated geometry
|===
