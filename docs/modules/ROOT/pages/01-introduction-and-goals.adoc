= 1. Introduction and Goals

== Purpose

Turn a software repository into an explorable 3D city and a printable model.

== MVP

* Analyze one or more local roots containing .NET/C#, TypeScript, or both.
* Explore the result in a browser.
* Export STL and profile-aware multi-part 3MF.
* Print an identity panel with name, version, and optional logo.
* Accept public GitHub repositories without breaking offline use.

== Quality goals

. Explainable metrics
. Deterministic output
. Private offline operation
. Printer-safe geometry
