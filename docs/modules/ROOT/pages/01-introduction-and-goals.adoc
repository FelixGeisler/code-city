= 1. Introduction and Goals

== Purpose

Code City turns a software repository into an explorable 3D city and a physical
model. It helps people see structure, complexity, dependencies, and change
without building or executing repository code.

== Capabilities

* Import Git repositories, source folders or ZIPs, and existing Code City models.
* Analyze C#, TypeScript, and JavaScript with syntax-aware front ends.
* Explore structure, metrics, findings, dependencies, and representative history.
* Export images, STL, and profile-aware 3MF print artifacts.
* Publish sanitized, immutable snapshots from a self-hosted deployment.

== Quality goals

. Explainable analysis rather than opaque scores
. Deterministic models and exports
. Safe handling of untrusted repositories and credentials
. Bounded behavior on modest self-hosted hardware
. One model shared by browser, history, and print workflows
