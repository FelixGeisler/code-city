= 13. Safe Extensions

Safe extensions are versioned JSON data, not executable plug-ins. They may define
bounded derived metrics, mappings, filters, legends, query results, overlays,
and an approved layout choice.

The extension boundary has no script, package, filesystem, network, credential,
or environment capability. Input is strictly validated before an isolated,
time-bounded worker evaluates a small expression language over a minimal model
projection. The main thread validates and binds the complete result to the exact
configuration and model before one application.

A preview starts from the immutable imported model and either applies atomically
or leaves the active city unchanged. Changing the project, frame, configuration,
or another projection invalidates it. Project-scoped configurations can be
reviewed and exported; administrator scope additionally requires deployment
approval bound to that exact configuration and model.

This boundary is for portable data-driven customization. Arbitrary code would
require a separate sandbox and threat model and is intentionally unsupported.
The schema and runtime validator, not this overview, are the compatibility
authority.
