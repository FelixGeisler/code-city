= Safe declarative extensions

Code City extensions are versioned JSON documents, not server-side plugins. They can declare derived metrics, color and geometry mappings, filters, legends, layouts, saved queries, and overlays. The public schema is `packages/core/schema/safe-extension.schema.json`; the strict runtime validator is the compatibility authority.

== Safety boundary

An extension has no JavaScript, TypeScript, WASM, command, URL, package, filesystem, network, credential, or environment capability. Derived metrics use a small typed expression tree (`constant`, built-in metric, arithmetic, min/max, `log1p`, absolute value) with finite numeric ranges, depth/node limits, and an operation budget. Evaluation runs in a cancellable browser module worker. The worker receives an already loaded city model and configuration only; it has no server-side filesystem, credential, or network access.

Import rejects unknown properties, unsupported versions, incompatible city-model versions, duplicate IDs, prototype-pollution keys, invalid cross references, and unbounded data. Invalid imports leave the city unchanged and present a diagnostic. Scripting is deliberately deferred: the declarative model is sufficient for the currently supported metrics and visual hooks, and a sandboxed scripting proposal would require a separate security design.

== Sharing, scope, and reproducibility

`scope.kind: project` configurations are portable project settings. `scope.kind: administrator` requires a bounded `approvalId`, allowing a deployment to approve a shared policy without embedding identities or credentials. Configurations state their exact format version and city-model compatibility (`1.x`). Only compatible deployments evaluate them; otherwise they fail closed. Built-in extension presets use this same public format.

The viewer's Metrics tab provides a labelled JSON import/preview/export flow. Preview evaluates without mutating the city; export writes exactly the reviewed JSON. Results are deterministic: building/filter IDs are sorted and numeric results are clamped to finite bounds.

== Migration

The migration API accepts only the immediately preceding data-only `codecity.extensions/0` shape and rewrites its version before strict validation. All other versions are rejected. Consumers should store the original JSON alongside the evaluated version for auditability.
