= 3. Context and Scope

[source,text]
----
Repository / ZIP / model
          |
          v
   Code City server  <---- Administrator policy and credential profiles
          |
          +----> Browser viewer
          +----> City/evolution artifacts
          +----> Image and print artifacts ----> Slicer / printer
          +----> Sanitized publication --------> Anonymous reader
----

[cols="1,2"]
|===
|Neighbor |Boundary

|Repository sources
|Read-only snapshots from local files, uploads, GitHub, Azure DevOps, or generic Git

|Administrator
|Inbound authorization, allowed network origins, credential profiles, retention,
and optional AI-provider policy

|Browser
|Same-origin viewer and versioned API; repository credentials never enter browser
state

|Slicer and printer
|STL or profile-aware multi-part 3MF plus manifests and private legends

|Anonymous reader
|Validated, sanitized, immutable published model and evolution artifacts
|===
