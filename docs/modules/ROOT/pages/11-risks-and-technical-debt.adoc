= 11. Risks and Technical Debt

[cols="1,2"]
|===
|Risk |Response

|Metrics imply false precision
|Expose formulas, raw and normalized values, caps, scales, and provenance

|A custom mapping hides or distorts missing data
|Record and enforce its missing-value policy; preview before an atomic apply

|Large repositories exhaust resources
|Apply file, time, memory, and archive limits

|Meshes slice differently across tools
|Validate and smoke-test representative exports

|Browser GPU limits or context loss prevent image export
|Preflight dimensions against GPU capabilities and a 512 MiB sample-aware
working-memory estimate; disable image controls during loss and show an
accessible fallback when WebGL cannot start

|Remote inputs enable SSRF or traversal
|Allowlist hosted providers and validate archives

|Language coverage is incomplete
|Report unavailable metrics explicitly
|===
