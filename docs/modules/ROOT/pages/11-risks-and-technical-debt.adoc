= 11. Risks and Technical Debt

[cols="1,2"]
|===
|Risk |Response

|Metrics imply false precision
|Expose formulas, evidence, missing facts, caps, and provenance; call findings
heuristics rather than verdicts

|Large or hostile inputs exhaust resources
|Validate before use, isolate work, enforce hard byte/count/time ceilings, and
cancel obsolete operations

|Remote access leaks credentials or reaches unintended hosts
|Require explicit origins and profiles, isolate credentials, reject redirects and
unsafe URLs, and persist neither source requests nor secrets

|Published data reveals private context
|Republish only sanitized validated artifacts; keep publication immutable and
revocable

|Browser or GPU behavior varies
|Use a tested WebGL 2 baseline, bounded fallbacks, explicit capability errors, and
nonvisual export paths

|Slicers interpret geometry differently
|Validate generated structure, provide calibration artifacts, and require an
operator print/slicer acceptance check

|Portable filesystem APIs cannot prove every platform ACL property
|Fail closed where possible and require explicit administrator attestations for
Windows trust boundaries

|Language and semantic coverage is incomplete
|Report unsupported facts explicitly instead of guessing
|===
