= 2. Constraints

* Repository content is untrusted data and is never built or executed.
* Local analysis and viewing must work without a network connection.
* Remote access is explicit and bounded by provider validation and deployment
  policy.
* C#, TypeScript, and JavaScript are the supported source languages in 1.0.
* The versioned city model is the contract between analysis, viewing, history,
  publication, and export.
* The production deployment is one non-root AMD64/ARM64 container with a
  persistent data directory and no mandatory external database or queue.
* Browser rendering requires WebGL 2. Chromium is the automated browser baseline
  for 1.0; unsupported rendering must fail accessibly without losing the model.
* Print output is printer-profile driven and must remain within declared physical
  capabilities.
* Inputs, work, persisted artifacts, and outputs are subject to hard resource
  ceilings.
