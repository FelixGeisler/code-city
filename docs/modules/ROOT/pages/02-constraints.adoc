= 2. Constraints

* The analyzer does not execute repository code.
* Local analysis and viewing work without network access.
* .NET/C# and TypeScript are the first analyzer targets.
* Browser and print output use one `city-model.json`.
* Export emits multi-part 3MF or single-material binary STL.
* Printer profiles declare configured print channels; no global channel limit
  exists.
* Browser export is local-only and does not auto-fit or tile an
  oversized city.
