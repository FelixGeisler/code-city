= Code City Architecture

Code City converts untrusted repository data into one validated, versioned city
model. The browser, history workflow, publication store, and print exporter all
consume that model.

These pages describe only the enduring boundaries, data flow, deployment shape,
quality goals, and decisions. Source code, schemas, and tests are authoritative
for protocol fields, numeric limits, and UI details that change more often.

Start with xref:03-context-and-scope.adoc[context and scope],
xref:05-building-block-view.adoc[building blocks], and
xref:06-runtime-view.adoc[runtime view]. Operational procedures are kept
separately in xref:14-release-and-operations.adoc[release and operations].
