= Overview

Code City turns a selected local working tree or public GitHub repository into a deterministic 3D city of
its supported JavaScript, TypeScript, and C# modules. Analysis runs in a browser
Web Worker; unsaved investigations consume no server analysis session or source
reservation. Explicit Save persists immutable investigations; shared URLs
reopen results and analyzed code without folder access, GitHub acquisition or parsing.

image::overview-flow.svg[Flow from a selected folder or repository URL to a complete Code City]

[cols="1,3",options="header"]
|===
| |Code City

|Input
|A read-only selected local folder or anonymously accessible public GitHub URL,
plus optional newline-separated canonical additional exclusions

|Selection
|Working-tree contents including uncommitted edits, identified from captured
content; or the supplied GitHub branch/release/default tip resolved to one
immutable commit on Analyze

|Output
|One deterministic city with sanitized per-file failure rows, or one terminal
failure with no stale or partial city

|Building
|One nonexcluded admitted source module

|Dimensions
|Height: source lines; footprint: executable units

|Colour
|Maximum executable-unit complexity
|===
