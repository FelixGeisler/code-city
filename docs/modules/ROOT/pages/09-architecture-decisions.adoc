= 9. Architecture Decisions

[cols="1,2"]
|===
|Decision |Rationale

|TypeScript monorepo
|Share model and logic across CLI, web, and workers

|Versioned city model
|Decouple analysis from rendering and printing

|Static analysis only
|Make untrusted repositories safe by default

|Native language front ends
|Use Roslyn and the TypeScript compiler API behind one fact schema

|Dependency overlay
|Keep streets structural; show directed, bundled routes on demand

|Local directory as canonical input
|Keep offline and remote paths identical after materialization

|Multi-part 3MF
|Preserve aligned, assignable tool volumes

|Antora with arc42
|Keep architecture concise, structured, and publishable
|===
