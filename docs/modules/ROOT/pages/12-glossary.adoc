= 12. Glossary

[cols="1,3"]
|===
|Term |Meaning

|Repository snapshot
|Bounded, read-only, transport-independent analyzer input

|City model
|Versioned validated data shared by viewer, history, publication, and exporters

|Metric mapping
|Versioned definition that maps analyzer facts independently to footprint,
height, and color with evaluation provenance

|District
|Visual representation of a directory or package grouping

|Building
|Visual representation of a source file

|Evolution bundle
|Validated baseline and ordered deltas for representative repository history

|Semantic group
|Printer-independent role such as base, route, identity, or complexity band

|Print profile
|Build volume, geometry limits, formats, and configured tool/material channels

|Published snapshot
|Sanitized immutable copy of one imported city and optional evolution bundle

|Retained source
|Optional private source artifact stored separately from the city model

|Safe extension
|Bounded declarative data evaluated without scripting or I/O authority

|Credential profile
|Administrator-owned provider credential scoped to explicit repositories
|===
