= 12. Glossary

[cols="1,3"]
|===
|Term |Meaning

|City model
|Versioned data shared by viewer and exporters

|District
|Visual representation of a directory or package

|Building
|Visual representation of a source file

|Repository snapshot
|Read-only normalized analyzer input

|Print profile
|Geometry, format, and configured channel capabilities for one printer

|Print channel
|One independently assignable tool or material input

|Semantic group
|Printer-independent role such as base, route, or complexity band

|Identity panel
|Printable name, version, and optional logo area on the city base

|Route anchor
|Elevated dependency endpoint joined to an explicit surface contact

|External node
|Fixed black box for a dependency target outside the analyzed source

|Print legend
|Companion mapping from short physical codes to repository-relative names
|===
