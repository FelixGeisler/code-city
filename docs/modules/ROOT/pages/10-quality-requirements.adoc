= 10. Quality Requirements

[cols="1,2"]
|===
|Quality |Acceptance

|Determinism
|Same revision, config, and input order variants produce identical layout and
bundle bytes

|Privacy
|Local analysis succeeds with networking disabled

|Explainability
|Every visual dimension links to a documented metric

|Printability
|Every artifact fits the usable profile volume; scaling stays profile-safe and
tiling keeps districts whole

|Performance
|Viewer input is bounded; instancing is required before raising the limits
|===
