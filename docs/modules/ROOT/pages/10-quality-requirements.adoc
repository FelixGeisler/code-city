= 10. Quality Requirements

[cols="1,2"]
|===
|Quality |Acceptance

|Determinism
|Same revision, canonical metric mapping, and input order variants produce
identical semantic groups, layout, legend, and bundle bytes

|Privacy
|Local analysis succeeds with networking disabled

|Explainability
|Every visual dimension links to its metric, formula, normalization, cap,
missing-value policy, scale, and mapping provenance

|Printability
|Every artifact fits the usable profile volume; scaling stays profile-safe and
tiling keeps districts whole; print consumes the mapping applied in the viewer

|Atomic reconfiguration
|Cancellation or invalid input preserves the active city; an applied
geometry change cannot retain stale routes, bounds, picking data, or print
previews

|Evolution playback
|Direct seeking is path-independent; a superseded seek cannot publish a stale
frame; reduced-motion mode performs no spatial interpolation; stable
selections and route controls survive while their lineage or route exists;
dependency changes and rebuilt route geometry describe the target frame

|Image export
|Semantic bounds make preset framing repeatable; output has the exact accepted
pixel dimensions and requested scene annotations but no viewer chrome; GPU,
memory, legend-fit, and WebGL failures are explicit

|Performance
|Viewer input is bounded; instancing is required before raising the limits
|===
