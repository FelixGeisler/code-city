= 10. Quality Requirements

[cols="1,2"]
|===
|Quality |Acceptance

|Determinism
|Same revision and config produce the same model

|Privacy
|Local analysis succeeds with networking disabled

|Explainability
|Every visual dimension links to a documented metric

|Printability
|Exports and identity details pass mesh and printer-profile bounds

|Performance
|Viewer input is bounded; instancing is required before raising the limits
|===
