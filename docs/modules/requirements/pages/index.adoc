= Product

== Current standalone M5 product

Code City is a standalone Node.js application for one anonymously accessible
public GitHub repository. The service owns revision selection, source
acquisition, parsing, metrics, deterministic city construction, temporary
source-result association, admission capacity, and cleanup. The browser owns
same-origin interaction and presentation and receives no source payload.

The stable source and metric behavior is defined in
xref:source-and-metrics.adoc[Source and Metrics]. City, failure, interaction,
and deferred Save behavior is defined in
xref:city-and-failures.adoc[City and Failures]. The exact temporary-custody,
network, capacity, and no-Save boundary is defined in
xref:standalone-m5-operating-policy.adoc[Standalone M5 Operating Policy].

The canonical built artifact is `dist/`. Its version-1
`package-manifest.json` records every public and private runtime byte with an
artifact-relative path, role, media type, length, and SHA-256 digest. The
artifact contains:

* `public/` for the source-free same-origin browser;
* `server/` for the native HTTP service and worker code;
* `parser/` for the pinned parser runtime and JavaScript, TypeScript, TSX, and
  C# grammar assets.

Only declared `public/` bytes are served. The manifest, server files, parser
files, and unlisted paths return `404`.

== Operation

`npm run build` creates the canonical artifact. `npm start -- <flags>` starts
only that built artifact. `npm run dev -- <flags>` performs a one-shot build in
`build/development/` and starts the same service; it provides no HMR or
WebSocket path and does not write `dist/`.

Only `--host` has a default (`127.0.0.1`). Operators must supply `--port` and
all five capacity flags:

* `--max-live-sessions`
* `--max-active-attempts`
* `--max-command-body-readers`
* `--max-command-body-bytes`
* `--max-retained-source-bytes`

No capacity value is a product default or deployment recommendation. A
non-loopback host requires an explicit canonical host. The approved exposure
boundary is loopback-first or deliberate unauthenticated trusted-LAN use for
public GitHub source only. Internet exposure, private repositories, FLOW, ADO,
authentication, and device deployment are not approved.

== User-visible behavior

The browser captures one public GitHub repository URL and optional additional
exclusions when Analyze is selected. It uses only the same-origin session,
analyze, cancel, and discard routes. Session identity, generations, attempts,
and the current source-free result exist only in browser memory.

From an accepted Analyze submission until its current terminal outcome, the
status area shows `Analyzing repository`, the existing `Cancel` action, and one
native indeterminate progress control labelled `Analysis progress`. The control
has no completion value because the session protocol exposes no measurable
completion feed. Revision selection and Analyze acknowledgement retain this
presentation. Completion, failure, invalid input, cancellation, session loss,
discard, page exit, and disposal remove it. Replacement removes the prior
presentation and shows one for the newest accepted submission.

The service resolves an explicit branch head or the default-branch head,
selects one immutable commit, acquires and validates the complete admitted
source set, continues supported per-file analysis failures, and returns one
deterministic city plus sanitized failed-file rows. Replacement, cancellation,
session loss, backpressure loss, and shutdown cannot publish stale work.
Successful or all-files-failed current results remain until Discard,
replacement, or session loss.

There is no automatic retry, reconnect, recovery, source view, Save, reopen, or
application-managed persistence. Raspberry Pi performance, concurrency,
memory, and deployment qualification remain pending.

== Verification and publication

`npm run verify` type-checks, runs tests, builds once, reproduces the manifest
and every recorded byte, drives the actual packaged server, worker, parser
assets, and browser with deterministic nonshipped provider evidence, verifies
joined signal shutdown, validates the immutable retirement evidence, and builds
this documentation. Missing or stale artifacts fail closed.

A protected-main publication uploads the exact audited manifest-bound
standalone artifact and its exact manifest/run publication record. Pages upload
and deployment capability plus hosted-analyzer observation were removed only
after the #625 cutover run, notice bytes, and all eight former analyzer `404`
responses passed the live gate recorded in
`publication/retirement-live-verification-v1.json`. The last script-free notice
may remain reachable. No claim is made that the Pages repository setting is
disabled, deleted, or changed.

== Approved whole-core target beyond standalone M5

Accepted xref:architecture:adr/0013-ownership-of-source-acquisition-analysis-and-saved-investigations.adoc[ADR 0013]
keeps server ownership of acquisition, analysis, and source-result association.
The later whole-core target adds explicit immutable Save/reopen and deeper
investigation outcomes. Storage, authentication, public API, Internet
operation, private-source integration, deployment topology, and recovery
technology remain unselected and are not implied by standalone M5.
