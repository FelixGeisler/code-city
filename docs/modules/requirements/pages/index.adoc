= Product

== Current implementation

Code City analyzes one anonymously accessible public GitHub repository in a
browser Web Worker. The browser owns immutable revision selection, source
acquisition, parsing, metrics, city construction, and the unsaved investigation.
The native Node.js HTTP host serves manifest-verified assets and explicitly
saved snapshots. It owns no repository-analysis worker, unsaved source dataset,
or per-tab analysis session.

Stable admission, language, and metric behavior is defined in
xref:source-and-metrics.adoc[Source and Metrics]. Presentation and the whole-core Save contract are defined in xref:city-and-failures.adoc[City and Failures].
Current custody and network rules are defined in
xref:browser-analysis-operating-policy.adoc[Browser Analysis Operating Policy].

== Build and operation

The canonical built artifact is `dist/`. The version-1 `package-manifest.json`
records each runtime file's artifact-relative path, public/private role, media
type, byte length, and SHA-256 digest.

* `public/` contains the browser UI, analysis worker, parser runtime, and grammar
  WASM. Only verified public records are served.
* `server/` contains the private asset host, snapshot store and isolated data
  validator, not repository analysis or sessions. Private files, the manifest,
  and unlisted paths return `404`. Saved data is outside the artifact.
* Active parser assets are public records under `public/parser/`. The package
  requires no empty directories, so file-only archive transport preserves its
  complete manifest closure. Older version-1 packages may retain a private
  `parser/` root; every file there remains subject to the same audit.

`npm run build` creates this artifact. `npm start -- --port <port>` starts it.
`npm run dev -- --port <port>` builds under `build/development/` and starts the
same host without writing `dist/`; there is no HMR or WebSocket path.

Only `--host` has a default, `127.0.0.1`. `--port` is required; `0` requests an
OS-assigned port. A non-loopback host requires `--canonical-host`. The former
session, attempt, command-reader, and retained-source capacity flags are not
accepted. Browser Web Crypto requires HTTPS or a secure localhost context.
The host supplies no TLS ingress, and an insecure browser context shows
`Browser analysis requires HTTPS or localhost.` without starting a worker.

== User-visible behavior

Analyze captures one public GitHub URL and optional exact path exclusions.
A dedicated worker resolves the revision, validates and acquires the complete
eligible source set, continues supported per-file failures, and constructs a
city from successful facts. The UI thread validates the result and presents it.
Repository content is data, never imported or executed as application code.

The xref:city-and-failures.adoc#browser-investigation-workspace[investigation
workspace] collapses setup after Analyze and makes the city primary. Find file,
and failed-file details are closed by default. Change repository reopens setup
without losing the result; Analyze submits the edited inputs. There is no
Discard or Reanalyze control or expandable navigation-instructions panel.
Buildings and districts are selectable without moving the camera.

From Analyze until a terminal outcome, show one native progress control and
Cancel. Phase labels are `Starting analysis`, `Resolving revision`,
`Preparing file inventory`, `Acquiring files X of N`, `Initializing analysis`,
`Analyzing files X of T`, and `Building city`. Once a positive total is known,
report real counts beginning at `0/N` or `0/T` in the phase label. The single
bar remains indeterminate until the candidate total is known, then advances on
a fixed work budget without resetting between acquisition and analysis. It
reaches completion only after result publication. It is not elapsed time,
throughput, or an ETA. Never display `0/0` or fabricate completion for a failure.

Cancel during acquisition aborts and settles the owned source reads before the
worker is released. After acquisition, cancellation can terminate the worker
without waiting for a synchronous parser to process a message. Replacement
invalidates old publication, stops old work, and starts only the newest local
submission. Late callbacks cannot restore discarded state. Page exit disposes
its local worker. Successful and all-files-failed results remain local until
replacement, page loss, or worker loss. Cancel after completion is a
no-op rather than a discard.

An idle tab creates no analysis worker or backend analysis request. Multiple
completed tabs do not reserve shared analysis capacity. Filtering, sorting,
selection, and camera interaction remain local.

Explicit Save, Copy link, and Open saved provide immutable shared snapshots,
a repository-grouped branch/release picker, and restart-persistent reopening
without GitHub acquisition or parsing. See
xref:saved-investigations.adoc[Saved Investigations] for data, limits and recovery.
There is no automatic saving/retry, source view, login, or browser persistence.

== Verification and publication

`npm run verify` checks types and tests, builds once, reproduces every recorded
byte, audits the actual package, verifies native shutdown, drives installed
Chrome with a synthetic provider through the production worker, and builds docs.
The browser gate covers real four-grammar results, CORS failure, blob integrity,
source limits, measured progress, cancellation, replacement, multiple tabs, and
a healthy 4,000-file / 40 MiB attempt. This is not a resource or latency promise.

Protected main publication uploads the audited `dist/` and its manifest-bound
run record. No Pages deployment is reactivated. The earlier live retirement
notice and former-analyzer URL evidence remain unchanged in
`publication/retirement-live-verification-v1.json`.

== Persistence boundary

xref:architecture:adr/0015-browser-analysis-and-server-saved-investigations.adoc[ADR 0015]
keeps computation and unsaved state in the browser. Shared immutable Save,
inventory, and reopen use the separately configured file store selected by
xref:architecture:adr/0016-immutable-investigation-file-store.adoc[ADR 0016].
`--data-dir` enables persistence; without it analysis remains usable.
No login, server metric certification, private-source support, or Internet
exposure is implied.
