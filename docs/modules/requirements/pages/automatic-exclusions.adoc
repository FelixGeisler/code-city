= Automatic source exclusions

Explicit Analyze applies one case-sensitive directory catalogue at every depth:

* Dependencies: `node_modules`, `bower_components`, `.pnpm-store`; only the pairs `.yarn/cache` and `.yarn/unplugged`.
* Generated outputs/reports: `dist`, `build`, `bin`, `obj`, `coverage`, `.nyc_output`.
* Framework/cache: `.angular`, `.next`, `.nuxt`, `.svelte-kit`, `.parcel-cache`, `.vite`, `.turbo`, `.nx`.

Reasons identify recognized conventions, not certified authorship. Similar names, `vendor`, `packages`, `generated`, generic `.cache`, `.yarn/plugins` and configuration remain included. No gitignore inference, manifest execution or content classification occurs. Local `.git` at any case remains non-overridable.

== Interaction and precedence

Folder selection alone performs no discovery. One Exclusions details panel contains one editable newline-path list. Detected excluded roots join user paths in that list, without a separate catalogue, reasons, checkboxes or paging. Removing a detected root stages its exact-root include exception for the next explicit Analyze; readding it excludes again. Manual exact/ancestor exclusions always win. Siblings and nested matching roots remain independent. Editing settings changes no current city, source, camera or GPU buffers and performs no automatic analysis or upload.

The editor retains manual/automatic provenance invisibly: unchanged populated lists never promote automatic paths to manual settings or change capture identity. Reports merge against current edits, never overwrite pending or invalid text, resurrect pending removals or move a focused editor's selection. Invalid paths remain invalid rather than being repaired silently. Submit reads programmatic text changes too.

A new attempt snapshots settings before work. Partial, failed, cancelled or all-excluded attempts keep available detections editable without claiming unseen descendants. Complete discovery can remove obsolete automatic-only rows. Late reports cannot replace newer source/attempt state. Source changes clear automatic-only rows and source-bound include exceptions but retain user manual paths. Saved results restore the effective list with original manual/include settings; working-tree reanalysis retains them through required explicit folder selection, without reconnecting a folder implicitly.

== Capture and Save

The recorded version-1 policy contains canonical sorted unique manual paths, exact included roots, detected path/rule pairs and effective exclusions (manual paths plus actually pruned automatic roots). Discovery never claims hidden descendants. Local pruning precedes descent/read; GitHub validates the complete inventory before filtering in both admission passes. Existing source budgets and read ownership remain unchanged.

Save records applied worker settings, never pending edits. Version-4 snapshots restore the same policy, source and city without folder, provider or parser acquisition. Unknown versions/rules, malformed or inconsistent policies and older snapshot versions are rejected, not migrated or deleted. Older receipts remain listable. Source-once envelopes and Save-only metadata bounds remain in force.
