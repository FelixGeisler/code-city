= Source and Metrics

Repository content is untrusted data. Code City never executes or imports it.

== Admission

[cols="1,3",options="header"]
|===
|Area |Rule

|Path
|Split a repository-relative `/` path into non-empty segments and normalise
each segment to NFC. Preserve case. Reject absolute forms, backslashes,
repeated or trailing separators, `.`/`..`, and control characters.

|Identity
|The canonical path. Exact or NFC collisions fail. Successful identities sort
by unsigned UTF-8 bytes.

|Suffix
|Compare the final suffix ASCII case-insensitively with `.js`, `.jsx`, `.mjs`,
`.cjs`, `.ts`, `.tsx`, `.mts`, `.cts`, or `.cs`.

|Kind
|Admit regular files. Skip directories, links, submodules and their descendants,
and unsupported suffixes. Do not apply vendor or generated-path exclusions.

|Content
|Decode strict UTF-8, remove one leading BOM, reject NUL, convert CRLF and CR
to LF, and perform no other transformation. Empty content is valid.
|===

== Supported processing envelope

These are Code City limits, not copies of GitHub limits. All maxima are
inclusive.

[cols="2,1",options="header"]
|===
|Measured value |Maximum

|Admitted modules |4,000
|Normalised UTF-8 in one module |2 MiB
|Normalised UTF-8 across all modules |40 MiB
|===

A repository outside this envelope fails as `Repository exceeds Code City
limits`. It is never sampled, truncated, or partially processed.

GitHub independently owns API, rate, response, and tree limits.
Code City does not copy those values into its product contract. A truncated or
otherwise incomplete provider result fails as incomplete source. Internal
buffers and counters are implementation safeguards and must not reduce the
published Code City envelope.

== Syntax

[cols="2,3",options="header"]
|===
|Suffix |Grammar

|`.js`, `.mjs`, `.cjs`
|JavaScript; reject visible JSX nodes

|`.jsx`
|JavaScript with JSX

|`.ts`, `.mts`, `.cts`
|TypeScript

|`.tsx`
|TSX

|`.cs`
|C#
|===

Parser errors, missing nodes, or recovery fail the complete attempt. Type
checking, name resolution, linting, and dependency analysis are not performed.

== C# metric contract

C# and ASCII-case `.cs` variants are supported by the production-selected,
pinned grammar recorded by
xref:architecture:adr/0007-static-syntax-with-pinned-tree-sitter-webassembly-grammars.adoc[ADR 0007].
The selection defines accepted syntax without claiming a C# language version.
C# metrics use this fixed contract:

* `S` counts each physical line containing non-whitespace, non-comment C#
  source. Declarations, attributes, metadata, and every preprocessor directive
  count. Comment-looking content in regular, verbatim, interpolated, and raw
  strings remains source. All syntactically present preprocessor branch bodies
  are analysed without symbol evaluation; directive conditions add no unit or
  decision.
* `U` counts one unit for each explicit body of a method, local function,
  constructor, destructor, operator, conversion, accessor (`get`, `set`,
  `init`, `add`, or `remove`), lambda, or anonymous method. Block and expression
  bodies count. An expression-bodied property or indexer is one getter unit.
  Auto accessors, bodyless, signature-only, abstract, extern, and generated
  members, and a primary-constructor header alone, count zero.
* Runtime field, property, and event initializers, top-level statements, and
  primary-constructor base arguments outside explicit bodies share at most one
  file-wide `initialization/top-level` unit. An explicit constructor initializer
  belongs to that constructor. Nested callables own their bodies exclusively,
  although creating one can establish the surrounding initialization unit.
  Attributes, type and signature syntax, parameter defaults, const
  initializers, and enum values establish neither a unit nor runtime ownership.
* Each unit starts at complexity 1. Add one owned point for each `if`, loop,
  switch-statement `case` label, `catch`, conditional expression, and occurrence
  of `&&`, `||`, `??`, or `??=`. Add one for each switch-expression arm except
  an unguarded discard arm (`_ =>`), and one more for each switch-arm `when`
  guard and catch `when` filter. Thus a guarded discard arm and a filtered
  catch each add two points. Multiple `case` labels each count; `default` adds
  zero.
* Patterns, query clauses, attributes, type and signature syntax, parameter
  defaults, const and enum syntax, preprocessor conditions, `else`, `switch`,
  `default`, `try`, `finally`, calls, comparisons, bitwise operators, and
  conditional access add no point themselves. `M` is the maximum unit
  complexity, or zero when there is no unit.

Any C# parser error, missing node, or recovery fails the whole
attempt as `Metric processing failed` / `M1-MET-1`, without a diagnostic,
partial result, retry, fallback, or source execution.

== Metrics

=== Source lines (`S`)

Count a physical line once when it contains non-whitespace, non-comment source.
Blank, line-comment-only, block-comment-only, JSDoc-only,
triple-slash-directive-only, hashbang-only, and JSX-comment-only lines count
zero. Comment-looking text in strings, templates, regular expressions, or JSX
remains source. A final LF adds no line.

=== Executable units (`U`)

Count body-bearing functions, arrows, methods, constructors, getters, setters,
and static blocks. Add exactly one `top-level` unit when value-level syntax
exists outside callable parameter/body, concise-expression, and static-block-body
regions. Comments, type-only syntax, ambient declarations, signatures, and
`export {}` alone do not create that unit.

=== Complexity (`M`)

For each unit:

[source,text]
----
complexity = 1
           + owned if statements
           + owned loops
           + owned non-default case labels
           + owned catch clauses
           + owned runtime ternaries
           + owned &&, ||, ??, &&=, ||=, and ??= occurrences
----

Nested units own their regions exclusively. Parameter defaults belong to their
unit; declaration expressions outside a unit belong to `top-level`. `else`,
`switch`, `default`, `try`, `finally`, optional chaining, comparisons, calls,
and erased TypeScript syntax add zero themselves.

`U` is the unit count. `M` is the maximum unit complexity, or `0` when no unit
exists.
