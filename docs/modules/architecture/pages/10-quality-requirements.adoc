= 10. Quality Requirements

[cols="1,3",options="header"]
|===
|Quality |Required evidence

|Determinism
|Repeated processing of the same admitted content produces the same facts and
city; identical camera state and input produce the same matrix and exact CPU hit

|Safety and privacy
|Adversarial repository and provider data remains inert, uses only the fixed
network boundary, and creates no credential or active content. Inspection paths
and approved group labels remain controller-owned `textContent`; identity does
not enter attributes, styles, WebGL, callbacks, logs, or release evidence

|Completeness
|When the fixed provider path returns complete source, a supported repository
inside the published envelope produces a complete result, not a sampled or
partial one

|Capacity
|Packaged-browser fixtures cover the exact module, per-module, and aggregate
maxima with dense and deep valid syntax and no private lower limit

|Atomicity
|Geometry, inspection, numeric district presentation/projection, aligned
semantic labels, canvas, inspector, persistent complexity legend, and revision
publish as one transaction; replacement,
cancellation, failure, resize, context loss, or stale interaction cannot publish
partial or stale output

|Resource ownership
|Provider, parser, worker, presentation, and listener resources follow the
lifetime and exactly-once cleanup rules

|Numeric correctness
|Concentrated and `N=G=4000` scenes renew plate-inclusive camera, exact
four-row label projection, deterministic accepted-only collision layout,
building-only picking, shared-centre exact `float32` representation, and the
`420+28N+24G <= 208420` upload envelope

|Accessibility
|Keyboard users can navigate and select every building without pointer
emulation; focus, instructions, status text, paths, facts, formulas, and palette
bands do not rely on colour alone

|Visual quality
|The city remains the visual focus, controls and interaction are intentional and
predictable, surface focus preserves metric-colour prominence, and the inspector
and persistent numeric legend remain clean, responsive, and readable. Representative review and textual-only
attestation are owned by https://github.com/FelixGeisler/code-city/issues/537[#537]
without a numeric aesthetic threshold

|Reproducibility
|Pinned dependencies and assets are verifiable, and production serves the exact
verified artifact
|===

Detailed examples and boundary cases belong in executable tests rather than in
this architecture chapter.
