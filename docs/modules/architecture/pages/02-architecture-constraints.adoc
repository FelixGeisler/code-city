= 2. Architecture Constraints

The following set is closed for this baseline. Each constraint links to its
normative requirement instead of copying detailed grammar, matrices, formulas,
precedence tables, or numerical thresholds.

[cols="5,6,4",options="header"]
|===
|Accepted constraint |Normative source |Evidence owner

|One canonical public-GitHub URL is the sole user input. Each syntactically
accepted current attempt selects and identifies one immutable selected
revision at the GitHub-designated default-branch tip.

xref:requirements:04-functional-requirements.adoc#canonical-url[Canonical URL

|https://github.com/FelixGeisler/code-city/issues/453[#453] and

anonymously unavailable conditions preserve the accepted privacy behavior.

xref:adr/0001-core-dependency-boundary.adoc[ADR 0001] is the accepted
source-dependency constraint.
xref:adr/0002-browser-only-runtime-and-github-pages-deployment.adoc[ADR 0002]
is the accepted runtime and deployment constraint: the exact production target
is `https://felixgeisler.github.io/code-city/` at origin
`https://felixgeisler.github.io`; Code City runs in one browser
UI/presentation main context and at most one same-origin dedicated processing worker,
with direct anonymous worker-to-Public-GitHub communication and no backend,
credential, or persistent product state. ADR 0002 also fixes topology-level
enforcement and cleanup ownership without changing ADR 0001.

xref:adr/0003-m1-core-strata-building-blocks-and-conceptual-ports.adoc[ADR 0003]
is the accepted internal core-strata, minimum-block, conceptual-port, bridge,
and exclusive-ownership constraint. Shell/build and Pages mechanism, provider
origins and requests, analysis and visualization technology, concrete source
mapping, exact message and port schemas, worker lifecycle/cancellation and
physical cleanup mechanisms, and deferred limits remain *deferred/not accepted
here* with their owners in #447 through #460 and #463.
