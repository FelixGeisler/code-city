= Architecture Constraints

* Public GitHub acquisition and TypeScript/WASM analysis run in a browser Web
  Worker, never on the UI thread or in the application server.
* Source is untrusted data. Code City never executes repository scripts,
  builds, tests, hooks, or dynamically selected code.
* Requirements own admission, algorithms, processing limits, and visual mapping.
  Dependency versions remain authoritative in `package.json` and its lockfile.
* Browser blob integrity requires Web Crypto: HTTPS or a secure localhost
  context. Direct insecure remote HTTP cannot perform analysis.
* Only `--port` is required. The host defaults to loopback; a non-loopback bind
  also requires a canonical host. No analysis-capacity setting remains.
* Private repositories, Internet deployment, TLS ingress, and Raspberry Pi
  performance/concurrency/memory qualification are not supplied.

== Package boundary

The canonical `dist/` artifact has a version-1 `package-manifest.json` describing
all public/private runtime bytes. `public/` contains the UI, worker, parser
runtime and WASM grammars. `server/` contains the private host, file store and
isolated snapshot validator, not repository-analysis implementations. Parser assets are under
`public/parser/`; the package requires no empty root directories. The version-1
file-manifest audit also accepts an older private `parser/` root, auditing every
file if present.

The host verifies every public record before serving only fixed manifest
asset routes and the bounded saved-investigation API. The manifest, server
code, and unlisted paths return `404`. Legacy
analysis routes are not mounted. Native analysis/session adapters remain
repository regression fixtures, not shipped server capabilities.

== State and storage

Unsaved investigations exist only in browser memory. There is no server
unsaved-source cache, idle-tab dataset, or account.
xref:adr/0015-browser-analysis-and-server-saved-investigations.adoc[ADR 0015]
assigns only explicit snapshots to server custody. The
xref:adr/0016-immutable-investigation-file-store.adoc[file store] uses a separate
configured data directory, atomic publication and isolated validation, without
recomputing metrics. Product bounds and recovery policy are authoritative in
xref:requirements:saved-investigations.adoc[Saved Investigations].
