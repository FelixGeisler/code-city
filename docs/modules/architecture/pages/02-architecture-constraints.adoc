= 2. Architecture Constraints

The following set is closed for this baseline. Each constraint links to its
normative requirement instead of copying detailed grammar, matrices, formulas,
precedence tables, or numerical thresholds.

xref:adr/0001-core-dependency-boundary.adoc[ADR 0001] is the accepted
source-dependency constraint.
xref:adr/0002-browser-only-runtime-and-github-pages-deployment.adoc[ADR 0002]
is the accepted runtime and deployment constraint: the exact production target
is `https://felixgeisler.github.io/code-city/` at origin
`https://felixgeisler.github.io`; Code City runs in one browser
UI/presentation main context and at most one same-origin dedicated processing worker,
with direct anonymous worker-to-Public-GitHub communication and no backend,
credential, or persistent product state. ADR 0002 also fixes topology-level
enforcement and cleanup ownership without changing ADR 0001.

xref:adr/0003-m1-core-strata-building-blocks-and-conceptual-ports.adoc[ADR 0003]
is the accepted internal core-strata, minimum-block, conceptual-port, bridge,
and exclusive-ownership constraint.

xref:adr/0004-framework-free-typescript-shell-built-with-vite.adoc[ADR 0004]
is the accepted shell/build constraint: future framework-free TypeScript
source is packaged by exact-pinned Vite as a `/code-city/` static entry with a
separate, non-inline, same-origin ES-module worker, while Vite, UI-framework,
and concrete DOM/Worker mechanisms remain outside application and domain
core. This is an accepted documented decision, not current implementation.
https://github.com/FelixGeisler/code-city/issues/452[#452] owns the initial
package and evidence, https://github.com/FelixGeisler/code-city/issues/459[#459]
owns successful integration, and
https://github.com/FelixGeisler/code-city/issues/460[#460] owns renewed
final-head production evidence.

xref:adr/0005-anonymous-github-default-branch-tip-resolution-via-rest.adoc[ADR
0005] is the accepted anonymous revision-resolution constraint. Native worker
Fetch makes exactly the bounded sequential GitHub metadata and omitted-`sha`
one-item commit-list requests, permits only case canonicalization, projects the
full lowercase 40-hex identity, and applies the fixed privacy, status, quota,
cancellation, and application-controlled cleanup policy. It retrieves no
source. This is an accepted documented decision, not current implementation;
https://github.com/FelixGeisler/code-city/issues/453[#453] owns its realization.

xref:adr/0006-bounded-selected-revision-retrieval-via-github-tree-and-raw-content.adoc[ADR
0006] is the accepted immutable selected-revision retrieval and sole-admission
constraint. Native worker Fetch obtains the selected commit object, its exact
recursive root tree, and at most one sequential immutable-commit raw response
per in-horizon candidate; bounded own-field projection, exact Git blob identity,
and #442's canonical horizons govern one complete set or terminal result. Its
global no-overlap, cleanup, replacement-coalescing, stop, and no-timing-promise
rules are mandatory. #454 owns focused evidence, #459 packaged-path evidence,
and #460 hosted renewal.

xref:adr/0007-static-syntax-with-pinned-tree-sitter-webassembly-grammars.adoc[ADR
0007] is the accepted static-syntax and phase-lifecycle constraint. Its
provider-drained barrier precedes every runtime, grammar, parse, and traversal
operation; pre-barrier cancellation waits for provider settlement and
`ATTEMPT_DRAINED`, while matching barrier receipt permits immediate hard
termination before zero or during active static operations. Ordinary terminal
paths delete parser handles before `ATTEMPT_DRAINED`. At most one usable worker,
parser set, provider slot, and raw/hash workspace overlap observably.

Pages source/action/workflow and deployment mechanism, visualization
technology, concrete source mapping, general message and port schemas, and
CC-09/PR-01 stay with their owners in #451 through #460 and #463. Static syntax,
SP-01 through SP-04, selected-revision retrieval, and RA-10/RA-11 are no longer
deferred.
