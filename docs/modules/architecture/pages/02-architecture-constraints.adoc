= Architecture Constraints

== Current implementation

* The application is a static TypeScript package built with Vite and runs in a
  browser main context plus one module worker. It has no application server or
  persistence runtime. See xref:adr/0004-framework-free-typescript-shell-built-with-vite.adoc[ADR 0004].
* The current provider is anonymous public GitHub. The browser resolves the
  default-branch head and retrieves source for that immutable commit under
  xref:adr/0005-anonymous-github-default-branch-tip-resolution-via-rest.adoc[ADR 0005]
  and xref:adr/0006-bounded-selected-revision-retrieval-via-github-tree-and-raw-content.adoc[ADR 0006].
* Repository content is untrusted data. It is decoded and parsed but never
  imported, executed, built, or tested. The static package applies its manifest-
  owned content security and connection policy.
* Supported languages, source admission, processing limits, metric semantics,
  and visual mapping are product constraints owned by
  xref:requirements:source-and-metrics.adoc[Source and Metrics] and
  xref:requirements:city-and-failures.adoc[City and Failures].
* Syntax analysis uses the pinned WebAssembly grammar boundary recorded by
  xref:adr/0007-static-syntax-with-pinned-tree-sitter-webassembly-grammars.adoc[ADR 0007].
* Presentation requires WebGL2 and follows the accepted browser presentation
  decisions linked from xref:09-architecture-decisions.adoc[Architecture Decisions].
* Dependency and tool versions are authoritative only in `package.json` and
  `package-lock.json`.

== Accepted target

xref:adr/0013-ownership-of-source-acquisition-analysis-and-saved-investigations.adoc[ADR 0013]
requires a Code City server to own acquisition, analysis, retained source-result
association, and optional saved investigations. The browser remains responsible
for presentation and investigation. Explicit Save creates an immutable shared
snapshot; temporary work is not silently saved.

The target must retain the product contracts linked above. In particular, it
must support per-file continuation after complete acquisition, recursive
hierarchy, source and unit drill-down, a complete sortable file inventory,
Save/reopen, and selection without automatic camera movement. These are
accepted constraints, not current capabilities.

== Unresolved design

The server technology, API or transport, process split, storage representation,
access and security mechanisms, deletion, backup, ingress, deployment topology,
and production resource values are unselected. Recursive geometry, ordering,
spacing, labels, and picking are also unselected. This documentation does not
choose them.
