= 5. Building Block View

image::building-blocks.svg[Main-context controller and presenter with the sole processing worker]

[cols="2,1,4",options="header"]
|===
|Block |Location |Responsibility

|UI attempt controller |Main application |Validate submitted URL shape; own the
current attempt, the sole city-payload validator, immutable inspection snapshot,
semantic hover and selection, exact path matching and result validation,
traversal, inspector and district-label identities, generation/token/publication
identity gating, and the single publication-root commit

|Worker bridge |Main and worker edge |Own the sole concrete worker handle;
validate closed, generation-tagged commands, outcomes, and lifecycle messages;
reject stale messages

|Semantic publication |Main edge |Own the native current-city path-search input,
result buttons, their DOM listeners, and inert result-path `bdi.textContent`;
forward only exact query and numeric canonical-index semantic callbacks

|Interactive presenter |Main edge |Own stage tokens and sessions, canvas and its DOM
input, immutable scene-centre camera, pointer capture, request epoch, building-only
CPU picking, exact numeric district projection snapshots,
one-program/two-pass WebGL city resources, and uniform-driven hover/selection
surface focus

|Worker pipeline coordinator |Worker application |Sequence capabilities and
suppress downstream work after failure or cancellation

|Revision selection |Worker application |Ask the GitHub gateway for the
immutable head commit of the repository's default branch

|GitHub gateway |Worker edge |Construct and perform fixed-origin anonymous
requests; return bounded primitive evidence

|Source retrieval |Worker application |Coordinate immutable tree and blob
retrieval, verify identities, and return canonically ordered source evidence

|Admission |Worker domain |Normalise paths and content, select modules, and own
the published Code City envelope and its limit result

|Parser adapter |Worker edge |Validate one syntax tree and translate it into
grammar-neutral observations

|Metrics |Worker domain |Consume normalised source and syntax observations;
own SLOC, executable-unit, ownership, and complexity rules

|City builder |Worker domain |Create one complete, aligned, renderer-neutral
`{geometry, inspection}` city
|===

The controller owns semantic facts and independently reconstructs the numeric
presentation snapshot. The presenter receives only opaque validated geometry
plus plate minima/dimensions, plate-inclusive `sceneBounds`, and centre; it
receives no group identity or path. Its closed numeric projection callback
contains no identity or token. Presenter input listeners map DOM events to the semantic event
families in
xref:adr/0011-interactive-webgl2-navigation-and-inspection.adoc[ADR 0011]. The
controller receives no DOM event and rejects stale generations, semantic
publication identities, query snapshots, or invalid indices before changing
semantics or sending visual state. A validated search reveal reaches the
presenter only as a numeric canonical index and exact numeric AABB-centre target.

== Dependency rule

[source,text]
----
edge ───────► application ───────► domain
  └──────────────────────────────► domain  (capability-local policy only)
----

Reverse dependencies are forbidden. Driving adapters enter application ports;
domain code imports no GitHub, browser, Worker, Tree-sitter, or WebGL API. Pure
camera and picking policy may remain in core, while mutable browser and WebGL
mechanisms remain at the edge. Transport moves data but does not classify
product failures. Only the controller changes visible semantic state. This
slice remains governed by xref:adr/0001-core-dependency-boundary.adoc[ADR 0001],
xref:adr/0003-m1-core-strata-building-blocks-and-conceptual-ports.adoc[ADR 0003],
the amended xref:adr/0011-interactive-webgl2-navigation-and-inspection.adoc[ADR
0011], and
xref:adr/0012-bounded-grouped-shaded-direct-webgl-city-presentation.adoc[ADR
0012].

[[data-boundaries]]
== Data boundaries

[cols="2,2,4",options="header"]
|===
|Value |From → to |Content

|Repository reference |UI → revision selection |The two non-empty URL path
segments as inert strings

|Selected revision |Revision selection → retrieval and controller |Repository
reference and GitHub's full immutable commit ID. Before retrieval, the worker
publishes the closed interim `REVISION_SELECTED` message containing only its
generation and revision. The controller retains it without displaying it while
work continues.

|Source evidence |GitHub gateway → retrieval |Projected tree records or one
bounded, identity-verified, strictly decoded source text value; no provider
object, provider URL, or raw buffer crosses this boundary

|Admitted module |Admission → parser and metrics |Canonical path and normalised
UTF-8 source

|Syntax observations |Parser → metrics |Primitive spans and events for lexical
exclusions, executable-unit boundaries and nesting, runtime/type-only regions,
and decision occurrences

|Module facts |Metrics → city builder |Canonical path and the three integers
`S`, `U`, and `M`

|City payload |City builder → controller |One source-free `{geometry,
inspection}` value. Geometry contains dense origins, sizes, colours, and bounds;
inspection contains aligned `{canonicalPath,S,U,M}` facts.

|Validated city |Controller validator → controller/presenter |Controller-owned,
non-aliasing geometry, inspection, and immutable numeric presentation snapshots.
The numeric presentation contains only ordered plate minima/dimensions,
plate-inclusive `sceneBounds`, and centre. The validated city separately owns
aligned `{root,identity}` district descriptors. The presenter receives geometry
and numeric presentation, never inspection, identity, or label data; it returns
only ordered numeric projection snapshots.

|Semantic event |Presenter/semantic publication → controller |From the
presenter: generation plus hover or activation index, one traversal action, or
an immutable closed district projection snapshot. From semantic publication:
generation, exact publication identity, exact query snapshot, and optionally a
numeric canonical index. Never a DOM event, fact, or browser object; query text
never enters the presenter.

|Semantic publication |Controller → DOM |One atomically committed native path
search, canvas, inert clipped district-label overlay, selection inspector, and
persistent noninteractive numeric complexity legend. Matching returns only
canonical ordered numeric indices; semantic publication assigns captured paths
to result `bdi.textContent`.

|Visual state |Controller → presenter |Generation plus opaque hover/selection
indices, or one validated numeric reveal `{index,target}`. The presenter
validates them and assigns focus/camera state around the fixed
plate-first/building-second redraw; never query text, inspection facts, paths,
search nodes, or plate indices

|Attempt outcome |Worker → controller |One closed, generation-tagged success or
failure payload. Every post-selection outcome carries the selected full revision;
pre-selection failures carry none.
|===

Concrete provider, parser, DOM, and WebGL objects remain at their edges.
Repository paths may be published only as wrapping, bidirectionally isolated
inspector or search-result `bdi.textContent`; approved grouped directory identities may additionally
be district-label `bdi.textContent`. They are never markup, attributes, styles,
object keys, shader text, URLs, resource locators, logs, or evidence. Evidence observers access geometry only
and do not retain or disclose inspection.
