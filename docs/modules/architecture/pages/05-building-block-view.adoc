= Building Block View

[cols="1,2,3",options="header"]
|===
|Layer |Block |Responsibility
|Domain |Repository/admission/metric/city policies |Deterministic validation, calculations, geometry, and camera/picking rules.
|Application |GitHub/local acquisition and project analysis |Resolve a Git revision or content-identified local capture; share normalization, input limits, canonical consumption, per-file continuation, measured progress and city construction.
|Browser worker edge |GitHub/local folder gateways, Tree-sitter adapter, production worker |Perform anonymous provider reads or pruned read-only directory access and parsing; retain source and analysis evidence locally; export explicit snapshots directly to the host; send presentation metadata and only explicitly requested bounded source excerpts to the UI.
|Browser main edge |Local worker transport and standalone controller |Own workers and generations, abort/drain provider work, terminate parser work, validate events, suppress stale publication, and dispose on page exit.
|Application |Unit and district inspection |Index retained facts, exact descendant aggregates, locations, source pages and owned highlight unions. Validate bounded palette-indexed spans from the coloring adapter.
|Browser worker edge |Shiki adapter |Color retained text with bundled grammars/theme and inline Oniguruma WASM; no HTML, acquisition or analysis-parser initialization.
|Domain |Recursive district layout |Iterative deterministic nested platforms; preserve the existing file-dimension and color functions.
|Presentation |Inventory, inspector, presenter |Filter/sort/select canonical file identities without moving the camera or reuploading geometry. Render paths and failures as inert text.
|Saved-data application |Snapshot codec/capture |Version-4 tagged origin and recorded exclusion policy, one normalized source copy, retained facts, bounds/references/presentation validation; no metric recomputation.
|Node edge |Native host and investigation store |Stream owned staging writes, isolate validation, publish immutable directories and bound reads. No repository analysis/session runtime is mounted or packaged.
|Delivery |Builder, manifest, audits, browser evidence, workflows |Reproduce exact bytes, verify parser/public-private closure, drive actual Chrome with controlled provider traffic, and bind artifact publication to its run.
|===

== Boundaries and ownership

A browser-local owner identity is not a server session or authentication. Opening
an idle page allocates no analysis worker and sends no command to the host.
The current worker owns normalized source and facts; the UI receives validated
city and failure/progress data. Unit inspection reads only selected bounded
metadata/source over a revision/generation/request-tagged local channel; it
adds no provider or server call. The display-only Shiki adapter runs lazily in that
worker against one retained file, preserving lexical context across source
windows. Palette indices and scalar-aligned spans are validated at the UI boundary;
coloring uses inert nodes and fixed styles, not HTML from a highlighter.
Only explicit Save uploads source/evidence;
the file store is independent of local analysis.
File-inventory interaction creates no provider or HTTP request. Open saved
loads receipt metadata only; selecting an entry loads its snapshot.

The pure versioned exclusion catalogue is shared by local pre-descent pruning,
both GitHub admission passes, UI reasons and v4 validation. The wire vocabulary
is pinned: future catalogue changes require a new policy version, not silent
reinterpretation. Workers freeze applied settings and publish session/generation-bound
policy reports before terminal close. UI edits stage only the next Analyze;
Save consumes the worker's recorded policy. Native validation imports this pure
policy closure without acquiring source. See
xref:adr/0021-recorded-automatic-exclusion-policy.adoc[ADR 0021] and
xref:requirements:saved-investigations.adoc[Saved Investigations].

Parser/runtime/worker URLs are fixed same-origin public assets. GitHub origins
are explicit CSP connections. Repository content cannot select executable URLs.
Server implementation and package manifest remain private.

Native worker/session adapters and the older browser entry are repository
regression references, not alternate production paths. No server fallback,
provider override, test selector, or environment fault flag is shipped.
