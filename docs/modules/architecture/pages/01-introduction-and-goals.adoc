= 1. Introduction and Goals

Code City turns one public GitHub repository into a deterministic 3D city of
its JavaScript and TypeScript modules.

== Architecture goals

[cols="1,3",options="header"]
|===
|Goal |Meaning

|Deterministic
|The same selected commit produces the same admitted modules, metrics, and city.

|Safe
|Repository content remains untrusted data and is never executed.

|Atomic
|The user sees one complete current city or no city.

|Bounded
|Source, processing, and rendering stay within the published envelope and
finite provider safeguards.

|Simple to operate
|The application is a static browser package with no backend or credentials.

|Understandable
|Core product rules stay separate from external mechanisms.
|===
