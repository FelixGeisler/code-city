= Introduction and Goals

Code City turns one immutable public GitHub revision into an interactive city.
The browser owns acquisition and analysis in a dedicated Web Worker; the native
Node.js service serves verified assets only. This boundary is selected by
xref:adr/0015-browser-analysis-and-server-saved-investigations.adoc[ADR 0015].

[cols="1,3",options="header"]
|===
|Goal |Response
|Use client computation |Run the shared TypeScript/WASM analyzer outside the UI thread.
|Avoid idle-user contention |Keep unsaved source/results in the browser; create no backend analysis session or reservation.
|Deterministic evidence |Preserve immutable identity, full acquisition, accepted algorithms, and stale-publication guards.
|Safe presentation |Validate worker results and render paths and metrics as inert data.
|Verifiable delivery |Close the package manifest, reproduce bytes, and exercise the actual packaged browser worker.
|Shared investigations |Later persist explicit client-created snapshots and reopen them without analysis; not implemented yet.
|===

Product behavior is authoritative in the requirements module. Persistence
technology, operation limits, and deletion/recovery are later decisions, not
claims about this milestone. No login, server metric certification, private
provider, Internet deployment, or device-performance guarantee is added.
