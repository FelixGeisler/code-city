= 12. Glossary

[cols="1,3",options="header"]
|===
|Term |Meaning

|Attempt
|Work started by one submitted repository URL.

|Selected revision
|The immutable commit at the head of GitHub's default branch when submitted.

|Admitted module
|One supported, valid source file included in the selected revision's complete source set.

|Core
|Product policy and application coordination independent from external mechanisms.

|Edge
|Code that translates browser, GitHub, Worker, parser, renderer, or build mechanisms.

|Complete city
|One aligned renderer-neutral geometry and inspection result produced by a
successful current attempt.

|Validated city
|Controller-owned, non-aliasing geometry, inspection, numeric presentation,
and aligned semantic district snapshots produced by the sole city-payload
validator.

|Numeric presentation
|An internal immutable value containing ordered district plate minima and
dimensions, plate-inclusive `sceneBounds`, and their centre. It contains no
path, group identity, label, projection, callback, or observer field.

|District plate
|One opaque, noninteractive prism under an existing packed virtual group cell.
It is rendered before buildings and is never a pick or focus candidate.

|District projection snapshot
|A closed immutable presenter result containing positive CSS dimensions and one
ordered numeric `{screenX,screenY,area,lateral}` row per plate. It contains no
identity, token, path, or DOM value.

|Contextual district row
|One reserved `20px` normal-flow row immediately after path search and before
the city viewport. Its single inert, clipped label publishes the
controller-resolved selected-over-hover district name through an isolated
`bdi.textContent`, and hides and clears that text when neither context exists.
Numeric projection does not control its visibility or layout. The row is hidden
from accessibility APIs, unfocusable, pointer-transparent, and never a pick
candidate.

|Semantic state
|The controller's current-generation inspection facts, resolved district
context, hover, selection, one contextual-row publication, and inspector
publication.

|Visual replica
|A presenter-owned opaque hover or selection index used only by the trusted
fill shader's surface-focus uniforms; the controller remains authoritative.

|Complexity legend
|The persistent, noninteractive six-band numeric `M` key atomically published
below every committed city.

|Presenter token
|An opaque staged-session identity that gains input and callback eligibility
only after the controller commits the current city transaction.

|Request epoch
|A presenter-local counter that invalidates queued hover work after camera,
gesture, lifecycle, or session changes. Navigation forgets retained pointer
coordinates; only fresh eligible movement can schedule replacement work.
|===
