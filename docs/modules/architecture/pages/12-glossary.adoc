= Glossary

[cols="1,3",options="header"]
|===
|Term |Meaning in this architecture

|Accepted target
|Approved product behavior and responsibility boundary that is not necessarily
implemented. The complete contract is in xref:requirements:index.adoc[Product].

|Additional exclusion
|A user-supplied exact canonical repository-relative path captured with an
Analyze attempt. Rules are owned by
xref:requirements:source-and-metrics.adoc#CC-CORE-SRC-05[Path exclusions].

|Aligned city
|One current worker result whose canonical-order geometry and inspection facts
have equal identity and count. It contains no source.

|Canonical path
|The validated repository-relative identity used for ordering and inspection.
Its normative rules are in
xref:requirements:source-and-metrics.adoc#authoritative-admission[Admission].

|Complete acquisition
|Validation of the entire recursive tree, including every raw ancestor, before
exclusion, suffix filtering, or blob reads. See
xref:requirements:source-and-metrics.adoc#CC-CORE-SRC-06[Complete acquisition].

|Current implementation
|The browser-only system evidenced at commit
`38e620c915866394ca4967f418eec9d3f6ec979b`.

|Generation
|A controller-assigned attempt identity used to prevent replaced, cancelled, or
stale work from mutating the current city.

|Immutable revision
|The full commit identity selected only by explicit analysis. See
xref:requirements:source-and-metrics.adoc#CC-CORE-SRC-02[Explicit immutable-revision analysis].

|Investigation
|The city, file selection, metrics, units, source evidence, and saved state
covered by xref:requirements:city-and-failures.adoc[City and Failures]. Current
implementation supports only the documented browser-session subset.

|Main context
|The browser execution context containing the controller, semantic publication,
and WebGL presenter.

|Saved investigation
|The accepted immutable server-owned snapshot created only by explicit Save. It
is not implemented. Its contract is in
xref:requirements:city-and-failures.adoc#CC-CORE-SAVE-03[Immutable saved snapshot].

|Source-free
|Containing geometry and inspection facts but no source text, parser tree,
provider response, or raw diagnostic.

|Worker
|The single current browser module worker that performs provider acquisition,
admission, parsing, metrics, and city construction.

|Unresolved design
|A target mechanism that has not been selected and must not be inferred from an
accepted outcome.
|===
