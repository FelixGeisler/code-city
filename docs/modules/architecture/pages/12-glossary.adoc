= Glossary

[cols="1,3",options="header"]
|===
|Term |Meaning in this architecture

|Additional exclusion
|A user-supplied exact canonical repository-relative path captured with an
Analyze attempt.

|Canonical artifact
|The `dist/` directory containing public browser bytes, private server/parser
bytes, and the version-1 package manifest.

|Canonical path
|The validated repository-relative identity used for ordering and presentation.

|Complete acquisition
|Validation of the entire recursive tree, including every raw ancestor, before
exclusion, suffix filtering, or blob reads.

|Current implementation
|The standalone M5 service and source-free same-origin browser selected by ADR
0014.

|Generation
|A strictly increasing session-scoped attempt identity that prevents replaced,
cancelled, or stale work from becoming current.

|Immutable revision
|The full commit identity selected only by explicit analysis.

|Retirement notice
|The separate versioned script-free Pages document stating that the former
in-browser analyzer is retired and the standalone artifact is deliverable.

|Saved investigation
|The later immutable server-owned snapshot created only by explicit Save. It is
not implemented in standalone M5.

|Source-free
|Containing geometry, presentation facts, and sanitized failures but no source
text, parser tree, provider response, or raw diagnostic.

|Worker
|One Node.js `worker_threads` worker that executes one admitted analysis
attempt. No browser analysis worker is shipped.

|Unresolved design
|A later mechanism that has not been selected and must not be inferred from an
accepted outcome.
|===
