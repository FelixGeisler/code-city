= ADR 0009: Main line and GitHub Pages

Status:: Accepted

== Context

The archived v1 product and the M1 work used different branch names while the
legacy documentation occupied the final application URL.

== Decision

* The active and default integration branch is `main`.
* The former v1 line is locked as `v1`; it is history, not a fallback or
  publication source.
* No active `v2` branch remains.
* Only protected `main` may publish the `github-pages` environment, with no
  administrator bypass.
* The final Code City application replaces legacy documentation at
  `https://felixgeisler.github.io/code-city/`.
* Documentation and application are not co-hosted.
* Building the application must not deploy it automatically. Final publication
  is an explicit reviewed action that deploys the exact verified artifact
  without rebuilding it.

== Consequences

There is one integration line, production publisher, origin, and artifact. The
archived branch preserves history but cannot release or overwrite production.
Detailed branch-migration evidence remains in the owning GitHub issue rather
than current architecture documentation.
