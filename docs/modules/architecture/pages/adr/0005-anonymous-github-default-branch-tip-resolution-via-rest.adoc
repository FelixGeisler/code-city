= ADR 0005: Default-branch head resolution

Status:: Accepted

== Context

A repository URL must resolve to one immutable revision without credentials or
a branch, tag, or commit selector.

== Decision

Through the xref:adr/0006-bounded-selected-revision-retrieval-via-github-tree-and-raw-content.adoc[GitHub gateway], request:

[source,text]
----
https://api.github.com/repos/<owner>/<repository>/commits?per_page=1&page=1
----

Encode the two repository-reference segments independently. Omit the `sha`
parameter so GitHub selects the repository's default branch. Read the first
full commit ID and use that immutable commit for the complete attempt. Use
GitHub REST API version `2026-03-10`.

There is no retry, alternate revision, stale result, or fallback provider.
GitHub owns response and rate limits.

== Consequences

A later submission may resolve a newer head. Movement of the branch cannot
change an attempt after its commit has been selected.
