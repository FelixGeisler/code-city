The vendor boundary contains exactly six files: the TypeScript source notice,
the distinct `tree-sitter-javascript@0.23.1` source-dependency notice, the
patch, production provenance, and the TypeScript and TSX WASMs. The notices
remain separate exact 1,080-byte MIT payloads with SHA-256 values
`49bf33cf78ef5897e4e161ce1517df7de1ae5042a65b6bcfd44401e0fc606559`
and
`2e0110e07abef7c2548b26ec9d6969775617ca539a0dc8dbeeb14d6452c711d1`.
Each payload is also carried once in deployed `index.html` by its labelled,
non-executable comment. The package therefore remains the same nine runtime
files; it does not emit either notice as a standalone file.

The TypeScript and TSX node-type files remain pinned at, respectively,
`c790a733fc756b54d4e54dceeb7d2d51e40d8b57136e70277753a75804cce3e3`
(108,583 bytes) and
`78b5789145286799a27a0a7ecc36cc1bcb151f94ec7fa631b248459867010c8c`
(113,345 bytes). The accepted `dylink.0` values are:

* TypeScript: memory 1,330,484, alignment 4, table size 7, table alignment 0,
  no needed libraries, and subsection `[1]`.
* TSX: memory 1,409,560, alignment 4, table size 7, table alignment 0, no needed
  libraries, and subsection `[1]`.

Only the TypeScript imported `env.memory` minimum and its normalized inventory
projection change, from 22 to exactly 21 pages. The fixed
`web-tree-sitter@0.27.0` host supplies 512 initial pages and a 32,768-page
maximum, so the lower descriptor is an instantiation minimum rather than a
capacity reduction. The remaining 217 inventory rows are byte-identical and
TSX remains at 22 pages.

`tools/build-parser-assets.mjs` is the manual maintainer reproduction route. It
reacquires the pinned public inputs, reproduces two controls and two patched
builds in the exact cached Emscripten image without build-time network access,
checks every output and intermediate, and publishes only the two WASMs to a
new system-Temp output. Ordinary verification independently checks committed
bytes and does not invoke that heavy route.

Issue https://github.com/FelixGeisler/code-city/issues/577[#577] is the immutable
decision and qualification record. It records the human-approved narrow
grammar amendment separately from the delegated Requirements Engineer choice
to package the two notices in labelled HTML comments.
