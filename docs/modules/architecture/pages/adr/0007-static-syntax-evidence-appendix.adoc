The vendor boundary contains exactly six files: the TypeScript source notice,
the distinct `tree-sitter-javascript@0.23.1` source-dependency notice, the
patch, production provenance, and the TypeScript and TSX WASMs. The notices
remain separate exact 1,080-byte MIT payloads with SHA-256 values
`49bf33cf78ef5897e4e161ce1517df7de1ae5042a65b6bcfd44401e0fc606559`
and
`2e0110e07abef7c2548b26ec9d6969775617ca539a0dc8dbeeb14d6452c711d1`.
Each payload is also carried once in deployed `index.html` by its labelled,
non-executable comment. The exact 1,133-byte C# source-grammar MIT payload,
SHA-256 `778fb7d63b8c1844da315648c02f325c4713a6f4a5d19644fd413421422776d3`,
follows those two comments under its pinned source-commit label. The package
contains ten runtime files: one HTML file, one stylesheet, three JavaScript
files, and five WASMs. No notice is emitted as a standalone file.

The TypeScript and TSX node-type files remain pinned at, respectively,
`c790a733fc756b54d4e54dceeb7d2d51e40d8b57136e70277753a75804cce3e3`
(108,583 bytes) and
`78b5789145286799a27a0a7ecc36cc1bcb151f94ec7fa631b248459867010c8c`
(113,345 bytes). The accepted `dylink.0` values are:

* TypeScript: memory 1,330,484, alignment 4, table size 7, table alignment 0,
  no needed libraries, and subsection `[1]`.
* TSX: memory 1,409,560, alignment 4, table size 7, table alignment 0, no needed
  libraries, and subsection `[1]`.

Only the TypeScript imported `env.memory` minimum and its normalized inventory
projection change, from 22 to exactly 21 pages. The fixed
`web-tree-sitter@0.27.0` host supplies 512 initial pages and a 32,768-page
maximum, so the lower descriptor is an instantiation minimum rather than a
capacity reduction. The remaining 217 inventory rows are byte-identical and
TSX remains at 22 pages.

`tools/build-parser-assets.mjs` is the manual maintainer reproduction route. It
reacquires the pinned public inputs, reproduces two controls and two patched
builds in the exact cached Emscripten image without build-time network access,
checks every output and intermediate, and publishes only the two WASMs to a
new system-Temp output. Ordinary verification independently checks committed
bytes and does not invoke that heavy route.

Issue https://github.com/FelixGeisler/code-city/issues/577[#577] is the immutable
decision and qualification record. It records the human-approved narrow
grammar amendment separately from the delegated Requirements Engineer choice
to package the two notices in labelled HTML comments.

The asset's `dylink.0` section has memory size 5,013,132, memory alignment 4,
table size 7, table alignment 0, no needed libraries, and subsection `[1]`.
Its sole memory is imported as `env.memory` with a 77-page minimum, no maximum,
and neither shared nor 64-bit memory. The canonical inventory records every
import, export, and memory descriptor; ordinary verification regenerates it
from the exact candidate and compares all bytes.

`test/fixtures/csharp-candidate.json` is the closed qualification provenance
and renewal record. `test/fixtures/csharp-source-license.txt` preserves the
exact source licence and supplies the production entry comment without an
additional runtime file.

`test/fixtures/csharp-qualification-cases.json` is the closed syntax and metric
table. `tools/qualify-csharp-grammar.mjs` and
`test/csharp-qualification.test.mjs` independently verify candidate identity,
direct runtime loading, complete iterative validation, concrete shape digests,
metric ownership, malformed-tree signals, and deterministic resource release.
Issue https://github.com/FelixGeisler/code-city/issues/602[#602] adds direct
adapter projection evidence against that unchanged table. Production admission
retains it and adds packaged-browser mixed-language, malformed-tree, envelope,
and exact dense/deep evidence. Every valid case is projected through the
packed, source-free observation stream and Metrics with
exact `S`, `U`, per-owner complexity, and `M`; every invalid case returns no
stream. Focused assertions cover complete unit spans, body-only and constructor
initializer ownership, runtime anchors, comments and Unicode byte endpoints,
excluded nesting, switch guards and defaults, catch filters, and all
preprocessor branches. Sequential evidence fixes one language load, one parse,
non-overlapping validation and projection cursors, bounded live resources, and
exactly-once idempotent stream release.

The evidence also generates and processes two 2,097,152-byte modules: one
method body with exactly 1,000,000 empty statements and one expression-bodied
method with exactly 100,000 nested parenthesis pairs. A trailing line comment
is the only padding. Both complete direct validation, projection, and metric
derivation with `S=1`, `U=1`, and `M=1`. No elapsed-time threshold is part of
the evidence.

The C# block is appended as the fifth block in the canonical inventory and is
byte-equivalent to `test/fixtures/csharp-wasm-inventory.tsv`.
`CANONICAL_PARSER_ASSET_URLS` supplies its exact Vite package URL and the
production worker requests the same-origin emitted WASM. Any change to the
package, asset, runtime, source commit, inventory, ABI, or licence requires
renewed qualification under ADR 0007 before production selection can continue.
