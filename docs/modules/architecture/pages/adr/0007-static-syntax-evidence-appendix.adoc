== Canonical serialization

The canonical inventory below obeys all of these rules:

* UTF-8 without BOM;
* literal TAB (`U+0009`) field separators;
* LF line endings only, including one final LF;
* no quoting, escaping, blank line, or CR;
* asset order: runtime, JavaScript, TypeScript, TSX;
* for each asset: `ASSET`, import header and rows, export header and rows,
  memory header and rows;
* import and export rows sorted by unsigned UTF-8 bytes over their
  NUL-separated field tuple;
* memory rows sorted by numeric index; and
* exactly `10,103` bytes and `217` rows, comprising `4 ASSET + 12 headers + 36
  imports + 161 exports + 4 memory`.

The runtime imports unshared, non-memory64 `env.memory` with 512 initial and
32,768 maximum pages: 32 MiB initial and 2 GiB maximum. JavaScript imports 6
pages without a declared maximum; TypeScript and TSX each import 22 pages
without a declared maximum. Runtime import modules are exactly `GOT.mem`,
`env`, and `wasi_snapshot_preview1`. Grammar exports are their named language
function plus constructors and data relocations.
