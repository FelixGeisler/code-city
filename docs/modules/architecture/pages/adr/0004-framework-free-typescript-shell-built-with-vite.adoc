= ADR 0004: Framework-free TypeScript shell

Status:: Accepted

== Context

M1 needs a small browser application, a separate worker, strict type checking,
and a production package below `/code-city/`.

== Decision

[cols="1,2",options="header"]
|===
|Choice |Value

|Build tool |`vite@8.2.1`
|Language tool |`typescript@7.0.2`
|UI |HTML, CSS, and browser ESM; no UI framework
|Type checking |Strict TypeScript check separate from bundling
|Worker |Statically addressed, same-origin, non-inline ES-module worker
|Public base |`/code-city/`
|===

The package exposes explicit development, type-check, test, build, and verify
commands. Production output contains only runtime assets.

== Consequences

Vite is a build mechanism, not an application framework or core dependency.
Changing either pinned tool requires reviewing its package, output, and browser
compatibility.
