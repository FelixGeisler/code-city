= ADR 0008: Browser-native WebGL2 presentation

Status:: Accepted

ADR 0011 xref:adr/0011-interactive-webgl2-navigation-and-inspection.adoc[amends
this M1 baseline] for the current interactive camera, aligned city payload,
outline draws, inert path labels, and lifecycle contract.

== Context

The fixed city needs deterministic 3D presentation. A rendering package would
add abstraction and dependencies without product benefit.

== Decision

* Use browser WebGL2 and GLSL ES 3.00 directly in the main context.
* Accept only the closed, source-free presentation model from
  xref:../05-building-block-view.adoc#data-boundaries[the city boundary].
* Defensively validate collection shape, count, finite numeric values, fixed
  colours, geometry, and bounds before creating WebGL resources. A model breach
  remains `M1-CITY-1`; `M1-PRES-1` starts only after a valid model reaches
  WebGL.
* Use one unit-cube geometry, one program, one vertex array, fixed buffers, and
  one instanced draw.
* Stage one detached canvas and disposable presentation session. Context-loss
  setup, initial sizing, upload, and draw must all succeed before atomic
  publication.
* If a required resize presentation fails, or the context is lost, dispose the
  current session and publish one presentation failure through the generation
  gate in xref:../06-runtime-view.adoc[Runtime View].

Use fixed trusted shader source. In the M1 baseline, repository-derived values
never became shader text, DOM markup, labels, object keys, or resource locators.
ADR 0011 now permits canonical paths only as controller-published inert
`textContent`; every other prohibition remains.

== Camera and clipping

Use the direction and fit from xref:requirements:city-and-failures.adoc[City and
Failures]. For bounds lengths `Lx`, `Ly`, and `Lz`, target `T`, and direction
`D`:

[source,text]
----
E_d = (Lx + Ly + Lz) / (2 * sqrt(3))
camera = T + 3 * E_d * D
near = E_d
far  = 5 * E_d
----

Target-relative city depth lies in `[-E_d,+E_d]`; camera-space depth therefore
lies strictly inside the selected clipping volume. The uploaded matrix maps
only target-relative coordinates.

== Float representation

For normalised module byte counts `B_i`, aggregate `B`, module count `N`, and
executable-unit counts `U_i`, the accepted envelope and syntax density prove:

[source,text]
----
B <= 41,943,040
N <= 4,000
U_i <= 1 + floor(B_i / 3)
max X or Z <= 13,993,012 < 2^24
max Y      <=  2,097,153 < 2^24
----

Dimensions are therefore exactly representable as `float32`. After subtracting
`T`, every minimum corner and endpoint is an integer or half-integer with
magnitude below `2^23`, and is also exact as `float32`. Changes to source
limits, metric density, layout, or representation must renew this proof and
its full-envelope tests.

== Consequences

The presentation adapter owns WebGL state and idempotent cleanup. City
construction stays pure and renderer-independent. The M1 baseline used no
renderer package, texture, font, external shader, animation, controls, second
rendering worker, restoration, retry, or fallback. ADR 0011 removes only the
no-controls consequence and adds fixed interaction without adding a package,
worker, restoration, retry, fallback, or animation.
