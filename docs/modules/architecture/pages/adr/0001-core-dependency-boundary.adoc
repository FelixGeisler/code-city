= ADR 0001: Core dependency boundary

Status:: Accepted

== Context

Product rules must remain independent from GitHub, browser, parser, renderer,
and build tooling.

== Decision

[source,text]
----
external mechanisms (edge) ─────► core
core                       ──X──► edge
----

Edge code may depend on core policy and values. Core code must not import
browser, network, Worker, Tree-sitter, WebGL, Vite, or another concrete edge
mechanism.

ADR 0003 refines the core into application and domain responsibilities. This
ADR does not require a package, interface, class, or runtime boundary.

== Consequences

Core behaviour can be tested without external systems. A new mechanism stays
at the edge unless a later accepted decision changes this boundary.
