= ADR 0002: Browser-only runtime

Status:: Accepted

== Context

Code City needs public GitHub data and a 3D browser presentation. Operating a
backend would add credentials, persistence, deployment, and trust boundaries
that the product does not need.

== Decision

* Ship one static application at `https://felixgeisler.github.io/code-city/`.
* Run the UI and WebGL presentation in the browser main context.
* Use at most one processing worker for GitHub access, admission, metrics, and
  city construction.
* Access Public GitHub directly and anonymously from that worker.
* Keep no Code City backend, proxy, database, service credential, or persisted
  product state.
* Pass only bounded commands and source-free results between worker and main
  context.

The worker boundary separates lifecycle and processing responsibility. It is
not a security sandbox or a source-dependency boundary.

== Consequences

The browser and GitHub CORS behaviour are runtime constraints. A provider or
processing failure produces no partial city. Reload clears product state.
