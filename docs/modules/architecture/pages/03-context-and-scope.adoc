=== Current boundaries

* User input crosses a logical trust boundary into the UI.
* Repository data crosses a second logical trust boundary from Public GitHub
  into the processing worker.
* Same-origin main/worker transport is a lifecycle boundary, not a trust
  crossing or security sandbox.
* The worker sends only one bounded, source-free, aligned geometry-and-inspection
  result to the main context.
* The controller independently reconstructs numeric plate data and aligned
  semantic district descriptors from validated facts and geometry. Only plate
  cells, plate-inclusive scene bounds, and centre cross to the presenter;
  directory identities and paths do not.
* The controller owns semantic hover, selection, district-name derivation and
  precedence, inert contextual-row text, and inert inspector text. The presenter
  owns browser input, WebGL, and the retained numeric district projection. It
  sends generation-tagged building events and one closed numeric projection
  snapshot through the captured-token gate; that snapshot does not control
  contextual label visibility or layout. Plates and the contextual row have no
  picking identity.
* No product data is sent to GitHub Pages after the static application loads.
* The current baseline has no backend, database, relay, telemetry service, or
  second provider.

== Approved target context

Accepted xref:adr/0013-ownership-of-source-acquisition-analysis-and-saved-investigations.adoc[ADR 0013]
introduces a Code City server boundary. The server receives an explicit public-
repository analysis request, acquires the selected immutable revision, analyzes
the complete eligible dataset, and owns the authoritative source-result
association and optional immutable saved investigations. The browser receives
presentation and investigation data and requests exact analyzed source on
demand.

Repository and user inputs remain untrusted at every boundary. Server platform,
API, storage, admission mechanism, deployment, and recursive presentation
mechanics remain unresolved. This target context does not claim that those
components exist today.
