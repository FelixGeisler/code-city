== Ownership target

xref:adr/0013-ownership-of-source-acquisition-analysis-and-saved-investigations.adoc[ADR 0013]
is **Accepted**. It assigns acquisition, analysis, retained source-result
association, and saved investigations to a server, with presentation and
investigation in the browser. It does not select the server, API, storage,
access, or deployment mechanism. The target remains unimplemented.

xref:adr/0002-browser-only-runtime-and-github-pages-deployment.adoc[ADR 0002]
is **Superseded by ADR 0013**. It remains the historical record for the
browser-only runtime and non-persistence choice that the current implementation
still exhibits. Supersession does not make the current server target implemented.
