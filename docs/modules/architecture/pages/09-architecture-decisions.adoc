= Architecture Decisions

Decision records own rationale, alternatives, status, and amendment history.
This page presents the architecture by theme, then preserves a complete history
index. It does not replace or change any decision record.

== Current architecture by theme

=== Dependency and policy ownership

Domain policy remains independent from provider and browser mechanisms;
application code coordinates capabilities; edge code adapts GitHub, worker,
parser, DOM, and WebGL APIs. xref:adr/0001-core-dependency-boundary.adoc[ADR 0001]
and xref:adr/0003-m1-core-strata-building-blocks-and-conceptual-ports.adoc[ADR 0003]
own these boundaries.

=== Static application and source analysis

The current system is a framework-free TypeScript browser application. One
worker resolves an immutable public GitHub revision, validates bounded source
evidence, and performs static syntax analysis with pinned WebAssembly grammars.
The related records are xref:adr/0004-framework-free-typescript-shell-built-with-vite.adoc[ADR 0004],
xref:adr/0005-anonymous-github-default-branch-tip-resolution-via-rest.adoc[ADR 0005],
xref:adr/0006-bounded-selected-revision-retrieval-via-github-tree-and-raw-content.adoc[ADR 0006],
and xref:adr/0007-static-syntax-with-pinned-tree-sitter-webassembly-grammars.adoc[ADR 0007].
ADR 0007's xref:adr/0007-static-syntax-evidence-appendix.adoc[evidence appendix]
records its qualification evidence.

=== Numeric city presentation and interaction

The browser constructs and validates bounded numeric city geometry, then uses a
direct WebGL2 presenter with fixed trusted shaders. Controller-owned state keeps
geometry, semantic inspection, search, interaction, and cleanup aligned. This
theme is governed by xref:adr/0008-browser-native-webgl2-instanced-city-presentation.adoc[ADR 0008],
xref:adr/0011-interactive-webgl2-navigation-and-inspection.adoc[ADR 0011], and
xref:adr/0012-bounded-grouped-shaded-direct-webgl-city-presentation.adoc[ADR 0012].

=== Release authority and evidence

Protected `main` is the only publishing line. A canonical package, manifest,
publication record, and eligible production observation bind reviewed content
to release evidence. xref:adr/0009-m1-main-line-and-github-pages-cutover.adoc[ADR 0009]
and xref:adr/0010-canonical-artifact-manifest-and-publication-evidence-contract.adoc[ADR 0010]
own these choices.

=== Accepted server authority

xref:adr/0013-ownership-of-source-acquisition-analysis-and-saved-investigations.adoc[ADR 0013]
assigns acquisition, analysis, retained source-result association, and saved
investigations to a server, while the browser owns presentation and
investigation. This accepted target is unimplemented and does not select the
server, API, storage, access, security, or deployment mechanism.

ADR 0013 supersedes only the browser-only runtime and non-persistence decisions
in xref:adr/0002-browser-only-runtime-and-github-pages-deployment.adoc[ADR 0002].
The current implementation still exhibits that historical browser-only shape.
