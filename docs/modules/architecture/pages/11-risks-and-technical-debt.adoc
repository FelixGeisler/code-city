= Risks and Technical Debt

[cols="1,2,2",options="header"]
|===
|Risk/gap |Consequence |Current containment
|Browser/provider constraints |CORS, rate limits, unavailable evidence, or missing Web Crypto can prevent acquisition. |Fixed anonymous routes, strict integrity/limits, explicit failures; HTTPS or secure localhost required.
|Browser resource variation |Large repositories consume the user's CPU/memory; not every device is qualified. |Dedicated worker, accepted input envelope, cancellation; actual Chrome evidence is not a universal capacity promise.
|Whole-attempt failures |Revision, inventory, integrity, envelope, or shared parser failure prevents publication. |Fail closed; continue only the supported per-file failures.
|Dense inspection data |Retained units/observations add client memory; dense files can have many units/contributions. |Packed retention, one-file presentation indexing, bounded complete paging and no physical-memory/latency promise.
|Unsaved loss |Reload or worker loss loses unsaved source. |Explicit Save is required; there is no automatic saving.
|Saved disk and anonymity |Full storage, interrupted writes or hostile uploads can deny writes. |Bounded isolated validation, independent reads/static routes, stopped-host operator recovery; no per-person quota or universal DoS guarantee.
|Shallow grouping |Current layout uses the existing grouping, not the full recursive target. |Deterministic current layout; no claim of recursive completion.
|===

Browser acquisition/analysis, successful-file inventory, actual phase progress,
and independent local tabs are implemented. Server analysis admission and idle
source retention are removed from the delivered host. Legacy native adapters
remain regression references only.

Immutable Save, repository/ref picker and restart-persistent URL reopen are
implemented, including explicit unit/source/contribution inspection. Remaining
work includes recursive presentation, portable interchange, and wider deployment
qualification. No login or server metric
certification is required. Anonymous operation controls are not a guarantee
against arbitrary network denial of service.
