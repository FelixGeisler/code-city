= Crosscutting Concepts

[cols="1,3,3",options="header"]
|===
|Concept |Current implementation |Authority and evidence

|Dependency direction
|Domain is independent; application coordinates source and analysis; Node edge
adapts GitHub, parser, worker, and HTTP; browser edge owns presentation.
|`src/domain/`, `src/application/`, `src/edge/node/`, standalone browser files

|Untrusted source and input
|Complete ancestry, canonical identity, content, command, worker, event, and
city checks occur before each downstream trust boundary. Source is data and is
never executed.
|xref:requirements:source-and-metrics.adoc[Source and Metrics], boundary tests

|Deterministic processing
|Captured exclusions, canonical paths, raw-read starts, canonical raw-outcome
consumption, parser assets, metrics, city construction, package paths, and
manifests have closed ordering and validation.
|requirements, domain tests, standalone manifest and reproducibility tests

|Temporary ownership
|Explicit capacity is reserved before work. Each acquiring attempt owns at most
eight pending or completed-not-consumed raw-read slots and settles them before
leaving acquisition. Source/result association remains in process memory and
is released after joined replacement, control, loss, or shutdown cleanup.
|xref:requirements:source-and-metrics.adoc[Source and Metrics] and focused
source-acquisition and GitHub-gateway tests govern the raw-read window and
settlement. xref:requirements:standalone-m5-operating-policy.adoc[Operating
Policy] governs privacy, attempt admission and capacity, and source custody;
session and signal tests cover joined lifecycle cleanup.

|Controlled publication
|The browser receives only source-free validated events and inert path/failure
text. Private server/parser/manifest bytes return `404`.
|standalone browser, HTTP perimeter, and package audits

|Reproducible release evidence
|The canonical standalone manifest and every recorded byte are reproduced. The
exact audited application artifact and the exact audited script-free notice are
uploaded through separate workflow inputs.
|xref:07-deployment-view.adoc[Deployment View], workflow tests
|===

Authentication, private-source authorization, saved-state retention/deletion,
backup, recovery, public ingress, and device operations remain outside
standalone M5.
