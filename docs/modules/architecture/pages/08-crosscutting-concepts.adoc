= Crosscutting Concepts

[cols="1,3,2",options="header"]
|===
|Concept |Current mechanism |Evidence
|Dependency direction |Pure domain rules; execution-neutral application sequence; browser worker integrations; native asset host. |Boundary/type tests and artifact import closure.
|Untrusted source |Validate complete inventory, blob identities, text, worker events, and presentation; source is never executable. |Admission, gateway, worker, and rendering tests.
|Determinism |Canonical starts/consumption/failures, pinned parser bytes, fixed metrics/geometry, reproducible manifest. |Domain/source tests and byte reproducibility.
|Temporary ownership |Source and results are local to the current browser worker. No backend session, source reservation, or idle dataset exists. |Browser transport tests, actual multi-tab and cancellation evidence.
|Safe publication |Local generation gates and validated city data; inert path/failure text. Public worker/parser assets are deliberate; private server and manifest return `404`. |Packaged browser and perimeter audits.
|Progress |Actual phase counts over the worker channel; the browser controller maps them to one fixed work budget after inventory admission. |Shared-core, controller, and packaged browser progress tests.
|Saved data |Separate format/build identities, atomic immutable publication, bounded isolated validation and independent reads; no provenance or metric certification. |Snapshot/store tests and restart/fresh-context browser reopen with provider access blocked.
|Release |One audited manifest-bound artifact and an isolated reproducibility build; no Pages deployment. |Workflow, package, publication, and retirement records.
|===
