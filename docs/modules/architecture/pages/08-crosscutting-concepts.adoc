= Crosscutting Concepts

[cols="1,3,3",options="header"]
|===
|Concept |Current implementation |Authority and evidence

|Dependency direction
|Domain is independent; application coordinates domain and capabilities; edge
adapts GitHub, worker, parser, DOM, and WebGL APIs.
|xref:adr/0001-core-dependency-boundary.adoc[ADR 0001],
`src/domain/`, `src/application/`, `src/edge/`

|Untrusted source and input
|Provider projection is not trust. Complete raw ancestry, canonical identity,
kind, content, protocol, and city checks occur before each downstream trust
boundary. Source is parsed as data and never executed.
|xref:requirements:source-and-metrics.adoc#CC-CORE-SRC-04[Untrusted source],
xref:requirements:source-and-metrics.adoc#CC-CORE-SRC-06[complete acquisition]

|Deterministic processing
|Captured exclusions and canonical paths have fixed ordering. Admission,
metrics, city construction, payload reconstruction, and camera policy use
closed rules; the same accepted facts have the same meaning.
|xref:requirements:source-and-metrics.adoc[Source and Metrics],
xref:requirements:city-and-failures.adoc[City and Failures]

|Atomic lifecycle
|Generation gates exclude stale work. Presenter and semantic content are staged
before one current publication; failure removes the complete city.
|xref:06-runtime-view.adoc[Runtime View], `src/application/main-controller.ts`

|Inert publication
|Repository-derived values enter the UI only through validated facts and text
nodes. They do not become markup, styles, URLs, shader input, logs, or release
evidence.
|xref:requirements:city-and-failures.adoc[Failure and privacy contract],
`src/edge/semantic-publication.ts`

|Resource ownership
|The worker releases provider/source/parser ownership by phase. Presenter
sessions own listeners, frames, pointer capture, WebGL resources, and canvas
state and clean them up idempotently.
|xref:05-building-block-view.adoc#data-boundaries[Data Boundaries],
`src/application/worker-attempt.ts`, `src/edge/city-presenter.ts`

|Reproducible release evidence
|The canonical build is rebuilt for reproducibility, audited over HTTP, bound
to a manifest and publication record, and deployed as one Pages artifact.
Production observation runs only when workflow eligibility permits it.
|xref:07-deployment-view.adoc[Deployment View],
xref:adr/0010-canonical-artifact-manifest-and-publication-evidence-contract.adoc[ADR 0010]
|===

The accepted target must preserve these concerns while moving analysis authority
and retained source to a server. Target authentication, authorization,
retention, deletion, backup, and operational controls are unresolved; current
browser safeguards must not be mistaken for those future policies.
