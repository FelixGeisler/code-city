= Runtime View

== Startup

The generated CLI parses all operator arguments before listening. `--host`
defaults to loopback. `--port` and all five capacities are required. A
non-loopback host requires a canonical host. The runtime validates the exact
version-1 package manifest, then verifies the length and SHA-256 digest of every
public record before listening. It preloads only those verified public bytes,
binds the native HTTP server, derives its canonical origin, and prints one
`READY` line. Startup does not read or hash private server or parser records;
the offline package audit verifies complete public/private manifest closure and
every recorded byte before publication.

== Analyze lifecycle

. The browser opens one persistent same-origin session response.
. Analyze consumes one strictly increasing generation. The server fully reads,
  decodes, and validates the command before changing lifecycle state.
. Replacement joins and releases prior work. Capacity is reserved atomically
  before worker creation.
. The worker selects an immutable revision, validates the complete source
  inventory, reads admitted blobs, initializes the parser once, continues
  supported per-file failures, and constructs a deterministic city.
. The parent validates the complete result and keeps it provisional until the
  worker exits normally.
. The session emits one complete JSON event per write. The browser validates
  session and generation identity before changing displayed state.

A successful result retains its exact normalized source association in process
memory. An all-files-failed result retains only the accepted current failure
association. Both expose Discard. The browser receives no source.

== Cancellation, replacement, loss, and shutdown

Cancel and Discard invalidate work, terminate and join an active worker, release
ownership, and then emit their control event. Replacement emits no synthetic
terminal event. Stale completion cannot restore discarded state.

A blocked NDJSON write, a second mutation while blocked, request abort,
response close/error, owning-socket close, unrepresentable browser input, or an
advanced command/protocol failure loses the browser-owned temporary session.
There is no reconnect or recovery.

SIGINT and SIGTERM stop admission, invalidate work, join workers, discard
retained state, close responses, and complete only with zero live sessions,
active attempts, and retained source bytes.

== Package and browser execution

The canonical artifact is `dist/`. `npm start -- <flags>` executes
`dist/server/standalone.mjs`. `npm run dev -- <flags>` builds an independent
artifact under `build/development/` and executes the same generated entry; it
has no HMR or WebSocket behavior and does not write `dist/`.

Installed-Chrome/CDP evidence drives the actual packaged browser, server,
worker, parser assets, and same-origin protocol with deterministic nonshipped
provider evidence. It covers success, continuation, replacement, cancellation,
discard, loss, capacity, page loss, private-file `404`, and exact browser
network closure without live GitHub.

== Deferred outcomes

Save/reopen, source view, authentication, private repositories, Internet
service, calibrated deployment values, and Raspberry Pi qualification are not
part of this runtime.
