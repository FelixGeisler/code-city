= Runtime View

== Current Analyze attempt

image::runtime.svg[Current browser analysis and atomic publication sequence]

. **Capture.** Analyze causes the controller to parse the repository and all
  additional exclusions as one input snapshot. Invalid input creates no worker
  or provider request. A valid replacement clears the old city and retires the
  older generation.
. **Select.** The one worker resolves the repository's then-current explicit
  branch head, or its default-branch head when no branch was supplied, and
  publishes the full immutable commit identity. An unavailable explicit branch
  fails without fallback.
. **Acquire completely.** The worker requests commit evidence by the selected
  commit ID, validates the matching commit and same-width root tree ID, then
  requests non-truncated recursive-tree evidence by that root tree ID. Edge
  projection is provisional. Domain admission validates every record's raw and
  canonical identity, kind, uniqueness, and every raw ancestor before
  exclusions, suffix filtering, or content reads.
. **Read sequentially.** Eligible blobs are fetched in canonical order by the
  selected commit ID, checked against expected object identities, decoded,
  normalized, and admitted one at a time. Branch text is not used in commit,
  tree, or raw-source routes. Any current content or provider failure aborts the
  complete attempt.
. **Process sequentially.** After all admitted source is available, the worker
  initializes syntax processing and derives metrics file by file, releasing
  source and parser projections as it proceeds. Any current syntax or metric
  failure aborts the complete attempt.
. **Construct and transfer.** The domain builds one deterministic city. The
  worker transfers aligned geometry and inspection facts, but no source.
. **Publish atomically.** The controller validates the entire payload, stages
  presenter resources and detached semantic content, rechecks generation
  eligibility, and commits one city. A staging, commit, or current presentation
  failure rolls the city back rather than exposing a partial result.

The exact product failure mapping belongs to
xref:requirements:city-and-failures.adoc[City and Failures].

== Current interaction and lifetime

The presenter converts keyboard, pointer, wheel, resize, and context-loss input
to generation-scoped semantic events. The controller owns search matching,
hover and selection state, inspection facts, and safe semantic text. Current
path-search activation selects and automatically reveals a building by moving
the camera; ordinary canvas selection does not. There is no source view.

Cancel aborts provider work while that work is abortable. Replacement and stale
callbacks cannot publish. Worker completion drains provider and source
ownership. Rollback, context loss, `pagehide`, or controller disposal removes
listeners, semantic nodes, canvas state, worker ownership, and WebGL resources
through idempotent cleanup.

== Accepted, unimplemented runtime outcomes

The target continues after eligible per-file text, syntax, or metric failures
and reports each sanitized failed-file outcome. It recursively represents the
successful hierarchy and provides a complete sortable successful-file inventory.
Selection is shared between city and list and does not move the camera. Explicit
unit drill-down shows exact analyzed source and owned contributions.

A completed analysis remains temporary until explicit Save. Save creates a new
immutable server-owned snapshot; reopen uses retained source and results without
GitHub acquisition or reanalysis. These outcomes are accepted, but no request,
transport, persistence, or cleanup flow has been designed or implemented.
