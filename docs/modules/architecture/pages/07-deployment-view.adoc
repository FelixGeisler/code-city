== Artifact path

Build the application once for one reviewed protected-`main` commit. Verification
and deployment consume the same immutable artifact; deployment does not rebuild
it. A manifest covers every production HTML, CSS, JavaScript, worker, WASM, and
other runtime asset with its path, length, media type, and SHA-256 digest.
Production contains no source map, test, documentation, or stale legacy asset.

Only protected `main` may publish the production Pages environment. The final
application replaces legacy documentation; documentation is not co-hosted with
the product.

== Browser policy

The entry document applies a default-deny content policy and no-referrer policy.
Executable code, styles, worker code, and WASM assets are same-origin; network
connections are limited to the two fixed GitHub origins owned by the gateway.
Objects, embedding, base-URL changes, and remote runtime assets are disabled.
Because GitHub Pages response headers and worker policy inheritance cannot be
assumed, the gateway's fixed-origin checks remain authoritative.
