= 7. Deployment View

This view is the authoritative implementation-independent deployment
synthesis accepted through
https://github.com/FelixGeisler/code-city/issues/463[#463]. It links ADR 0002's
production target, browser-only contexts, direct-provider topology, and trust
crossings to ADR 0004's conceptual `/code-city/` static package, ADRs 0005 and
0006's exact GitHub origins, ADR 0007's five same-origin parser assets, and ADR
0008's embedded trusted shader literals and browser-native presentation.

These decisions create no current M1 shell, source, dependency, configuration,
asset, package, traffic, renderer, route, workflow, or deployment mechanism.
This view selects no source map, executable schema, emitted filename, worker-
creation timing, transport/cancellation primitive, preload policy, or test
technology.

The production delivery URL is exactly
`https://felixgeisler.github.io/code-city/`, and requests originating from the

Adopting this existing target and base does not adopt its current Pages source,
action/workflow, application route, or deployment mechanism.

UI current-attempt/publication ownership and presentation-resource ownership
remain separate from every worker owner in the matrix. Source-dependency
arrows, runtime calls, runtime messages, deployment placement, and logical
trust crossings remain distinct.

The conceptual open path is exactly:

[source,text]
----
https://felixgeisler.github.io/code-city/
  → trusted static package beneath /code-city/
  → browser UI main context
  → Initial with empty draft and no status, tuple, city, history, or restored state
----

This path does not select an emitted filename, application route
implementation, Pages source, action/workflow, deployment mechanism, worker-
creation timing, or preload policy. Parser runtime/grammar assets become
eligible only after the accepted static barrier, never during provider-capable
processing.

== Security invariants

* The only logical trust crossings are exactly:
** `User → UI main context`;
** `Public GitHub → processing worker`.
* Same-origin bridge traffic and GitHub Pages artifact delivery are not logical
  product-data trust crossings.
* No user or service credential is requested, accepted, read, retained, or
  transmitted.
* Repository metadata, paths, bytes, and source remain untrusted and inert.
  They are never executed, evaluated, imported, or dynamically loaded.
  Repository data cannot construct, alter, or select an asset URL or introduce
  a capability.
* The canonical path's final suffix selects one grammar family only through
  ADR 0007's closed mapping to already-packaged JavaScript, TypeScript, or TSX
  grammars. It never selects an asset URL, plugin, or new capability.
* The UI performs no GitHub/provider request. Pages receives no product data.
* Cross-boundary content remains limited to validated primitive resolution
  evidence; bounded selected-revision records/bytes, with retrieval/admission
  alone creating the complete admitted set; fresh primitive static-syntax
  observations; selected identity, one fixed terminal failure, or one complete
  source-free canonical scene through the bridge; and the two discriminator-
  plus-correlation lifecycle attestations.
* Raw/normalized source, provider objects, admitted modules, parser objects,
  metric intermediates, and partial scenes never reach presentation.
* Building identities remain inert model keys and never become normal-object
  keys, DOM/WebGL names or text, shader content, resource locators, or logs.
* The worker remains only an execution/lifecycle context, not a security
  boundary, sandbox, operating-system process, package, component, or trust
  crossing.

== Stop rules

Stop this documentation change rather than assume or broaden scope if:

* an accepted requirement and ADR contradict;
* any stage, failure, cleanup action, or retained datum lacks one accepted
  owner;
* the flow cannot use all 13 exact ports without adding a port, block,
  abstraction, admission path, classifier, or orchestrator;
* accurate synthesis requires changing a requirement, ADR, navigation file, or
  any path other than `docs/modules/architecture/pages/03-context-and-scope.adoc`,
  `docs/modules/architecture/pages/06-runtime-view.adoc`, and
  `docs/modules/architecture/pages/07-deployment-view.adoc`;
* implementation detail would require selecting any deferred item above;
* a required mechanism needs another origin, request, retry, fallback,
  credential, runtime context, asset, renderer, parser, threshold, timing
  outcome, or weaker security/lifecycle rule; or
* an ADR renewal or stop condition is met.

The exact conflicting authorities return to their owning issue. No gap is
repaired in #463, and a newly discovered consequential choice is a blocker,
not an implementation decision.
