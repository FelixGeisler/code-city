= Deployment View

== Standalone application artifact

The repository produces one canonical manifest-bound application artifact in
`dist/`. It contains the source-free browser and private Node server, worker,
and parser assets. The repository does not host or deploy that service. An
operator may run the artifact on loopback, or deliberately on a trusted LAN for
public GitHub source, by supplying the required port and capacity values.

No device, Internet, authentication, private-source, performance, concurrency,
or memory deployment claim is made. Raspberry Pi qualification remains
pending.

== Verification path

Pull-request CI performs locked install, dependency closure, high-severity
security audit, the isolated Node type check, and `npm run verify`. That root
gate runs type checking and tests, builds the canonical artifact once,
reproduces its manifest and every recorded byte in an isolated directory,
drives the actual packaged server/worker/parser/browser, verifies signal
shutdown, validates the immutable retirement evidence, and builds the docs. It
does not publish.

== Main publication path

A protected-main push repeats the same gates and creates a publication record
bound to `dist/package-manifest.json`, the exact commit, and the workflow run.
It uploads the exact audited `dist/` directory as the standalone artifact and
uploads the manifest plus publication record as internal identity evidence.
No Pages upload or deployment action, Pages or ID-token write permission,
`github-pages` environment, eligibility query, or hosted analyzer observation
job remains.

== Completed retirement cleanup

`publication/retirement-live-verification-v1.json` records the exact #625 merge
commit and successful automatic Publish run, every uploaded artifact ID and
downloaded ZIP SHA-256, equality of the uploaded standalone manifest and its
publication-record binding, exact live root and `/index.html` notice bytes, and
`404` responses for all eight URLs in
`publication/former-analyzer-assets-v1.json`. Its request and checkout
timestamps establish that the live gate completed before cleanup editing.

The cleanup removed repository workflow deployment capability and the obsolete
hosted-analyzer observer only after that gate passed. The last script-free
notice may remain reachable. This repository makes no claim that the GitHub
Pages repository setting was disabled, deleted, or changed.

== Later deployment design
