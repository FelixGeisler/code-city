= Solution Strategy

== Current standalone strategy

. The browser opens one same-origin NDJSON session and keeps its session ID,
  generations, attempts, and current source-free result in memory.
. Analyze sends the captured repository URL and exclusions to the service.
. The service validates the complete command before lifecycle or capacity
  mutation, replaces prior work through joined cleanup, and atomically reserves
  worker and source capacity.
. One worker resolves the selected branch or default head to an immutable
  commit, validates commit and tree evidence, acquires admitted blobs through a
  bounded eight-slot raw-read window with canonical outcome consumption and
  joined cleanup, and retains normalized source only for the current temporary
  result.
. One initialized parser capability continues supported per-file text, syntax,
  and metric failures, constructs a deterministic city from successful facts,
  and returns sanitized failed-file rows.
. The parent validates the worker result and joins normal worker exit before a
  terminal event can become current.
. The browser validates exact events, generation-gates late values, and renders
  the source-free city through the existing presenter.

Cancel, Discard, replacement, session loss, backpressure loss, and graceful
shutdown invalidate work before joining workers and releasing ownership. No
retry, reconnect, recovery, Save, or browser-side analysis fallback exists.

== Dependency direction

Domain code owns deterministic policies. Application code owns acquisition and
analysis sequencing. The Node edge owns GitHub, parser, worker, HTTP, and
shutdown integration. The browser edge owns same-origin session control and
presentation. Package and workflow tools own deterministic closure,
reproducibility, runtime audits, and publication binding.

== Later target strategy

The later whole-core target adds explicit immutable Save/reopen and deeper
investigation behavior while preserving server authority. Storage, identity,
authorization, public API, private providers, and deployment technology remain
unselected.
