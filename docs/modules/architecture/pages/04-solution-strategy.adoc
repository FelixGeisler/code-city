= 4. Solution Strategy

== Approved target strategy

[cols="1,3",options="header"]
|===
|Strategy |Approach

|Stable input
|Capture the repository and validated canonical additional exclusions only on
Analyze or Reanalyze, resolve the default branch then, and bind one complete
analysis to that captured pair and immutable commit.

|Server authority
|The server owns source acquisition, analysis, and the authoritative association
between source, results, and optional saved investigations, as fixed by
xref:adr/0013-ownership-of-source-acquisition-analysis-and-saved-investigations.adoc[ADR 0013].

|Browser investigation
|Keep city presentation, selection, metrics, and on-demand exact-source
investigation in the browser.

|Independent core
|Keep validation, admission, metrics, city construction, and state policy free
of external mechanism APIs.

|Bounded processing
|Validate complete recursive-tree raw/canonical identity, kind, and ancestry;
then apply fixed and captured additional exclusions before blob reads and the
published source limits; then continue across individually unsupported or
unanalyzable files.

|Fixed syntax and mapping
|Retain pinned Tree-sitter grammars and the fixed globally bounded visual
mapping without executing repository content.

|Atomic publication and saving
|Publish no partial city; explicit Save creates a new immutable server snapshot
or none.
|===

Runtime, API, storage, access, deletion, backup, ingress, deployment, recursive
presentation, and portable-interchange mechanics remain unresolved. The target
strategy does not claim an implemented or deployed server.

== Current implemented strategy

The current static browser package validates and captures the repository and
additional exclusions on Analyze, resolves the default branch, uses
one ordered worker pipeline with explicit limits, accesses anonymous GitHub REST
and raw content directly, uses pinned Tree-sitter WebAssembly grammars, builds a
renderer-neutral city, presents it with browser-native WebGL2, and atomically
publishes only the current complete attempt. Direct provider access,
browser-owned analysis, two-segment grouping, and session-only results are
current transitional implementation details rather than the approved target ownership and
persistence strategy.

The architecture prefers explicit, single-purpose parts over speculative
extension points, fallbacks, plugins, or configurable pipelines.
