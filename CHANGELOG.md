# Changelog

All notable changes to Code City are documented here. The project follows
Semantic Versioning from version 1.0.0 onward.

## [1.0.0]

### Added

- Browser-based 3D exploration for TypeScript, JavaScript, and C# repositories.
- Local folder, repository ZIP, generated-model, public GitHub, Azure DevOps,
  HTTPS, SSH, and scp-style Git import workflows.
- Representative first-parent repository history with bounded, reproducible
  evolution frames and timeline playback.
- Source hierarchy, dependency exploration, findings, advanced queries, metric
  mapping, image export, and opt-in AI guidance.
- Deterministic STL and 3MF print exports, multi-plate layouts, physical labels,
  dependency routes, calibration artifacts, and Prusa XL five-tool allocation.
- Immutable published-city snapshots with anonymous view links, permanent
  version links, history, republishing, revocation, and privacy sanitization.
- Persistent self-hosted jobs, retained-source controls, credential profiles,
  inbound authorization, and hardened outbound repository policy.
- Multi-architecture Linux container support for AMD64 and ARM64.

### Security and reliability

- Non-root, read-only application container with private persistent storage.
- Strict archive, path, model, evolution, request, credential, and network
  validation with bounded memory, time, and concurrency policies.
- Real public-repository import, browser performance, print fidelity, security
  audit, documentation, and container checks in CI.
- Apache License 2.0, security reporting policy, third-party notices, release
  contract validation, and reproducible tag-only release preparation.
