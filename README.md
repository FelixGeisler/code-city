# Code City v2

Code City v2 is starting from a clean repository state. Product requirements
and architecture will be developed before implementation begins.

The released v1 implementation remains available on the `main` branch and at
tag `v1.0.0` for comparison.

## Documentation

Requirements, architecture, and comparison material are maintained as an Antora
site under `docs/`.

```bash
npm ci
npm run docs:build
```
